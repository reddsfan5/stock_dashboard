# 34 · 阅读 / 心法板块

前辈心法、技巧、买卖逻辑等长文的阅读页。内容与配置入库，页面由生成器再生（`output/` 不入库）。

- 书库首页：<http://127.0.0.1:8765/reading.html>
- 文章页：`http://127.0.0.1:8765/reading/<id>.html`（首篇：`/reading/chaogu-yangjia.html`）
- 生成：`python -m scripts.reports.gen_reading`（日更 `refresh_apps` 与 `minute_viewer --serve` 启动时也会自动生成）

## 文件

| 路径 | 作用 |
|---|---|
| `config/reading.yaml` | 分类（前辈心法 / 技巧 / 买卖逻辑，可增）、提示框类型、文章列表 |
| `config/reading_glossary.yaml` | 共享术语表（释义、别名） |
| `content/reading/<id>/article.md` | 文章正文；图片放 `images/`，正文用相对路径引用 |
| `scripts/reports/reading_markdown.py` | 零依赖 Markdown 渲染器（含下述扩展） |
| `scripts/reports/gen_reading.py` | 生成书库页、文章页，复制图片到 `output/reading/<id>/` |
| `scripts/services/static/reading.{css,js}` | 排版、目录、进度、术语气泡、放大、mermaid 懒加载 |
| `scripts/services/static/vendor/mermaid/` | mermaid 11.17.2（本地托管，文章含图示时才加载） |
| `scripts/tools/qa_reading.py` | 登录后的浏览器回归（1440 / iPhone 13），截图到 `output/ui-qa/reading/` |

## 版式

- 正文栏宽按"每行汉字数"配置：`config/reading.yaml` 的 `layout.measure_chars`（标准，默认 56）与 `layout.wide_chars`（宽栏，默认 70），随 A−/A+ 字号缩放；视口不够时自动收窄。对应 CSS 变量 `--rd-measure-ch` / `--rd-wide-ch`。
- 桌面端工具栏：「☰ 目录」收起/展开侧栏目录（目录头部也有「« 收起」，收起后右下角有悬浮「目录」按钮），「↔ 宽栏」切换标准/宽栏；状态存本机（`rdToc`、`rdWidth`），快捷键 T / W。
- 侧栏目录宽度：>1500px 为 250px，1101–1500px 为 220px，861–1100px 为 210px；≤860px 改为底部抽屉（「☰ 目录」悬浮按钮）。

## 新增一篇文章

1. 建目录 `content/reading/<id>/`，放 `article.md` 和 `images/`（`id` 用小写字母、数字、连字符）。
2. 在 `config/reading.yaml` 的 `articles` 加一条：`id`、`title`、`category`（分类 id）、`author`、`summary`、`tags`、`order`、`glossary_auto`、`added`；`source` 省略时默认 `content/reading/<id>/article.md`。
3. 运行 `python -m scripts.reports.gen_reading`，刷新书库页。终端会提示找不到的图片、未闭合的提示框、术语表里没有的 `[[术语]]`。

新增分类：在 `categories` 里加 `id / name / icon / description`，顺序即书库分区顺序。

## 系列（series）

多篇文章可以组成一个有序系列（如"Asking 系列""职业炒手系列""炒股养家系列""钙片系列""章盟主系列""巴菲特系列""赵老哥系列""小鳄鱼系列""退学炒股系列""芒格系列""段永平系列""利弗莫尔系列"），全部由 `config/reading.yaml` 驱动：

```yaml
series:
  - id: asking                # 小写字母/数字/连字符
    name: Asking 系列
    category: masters         # 系列所属分类（文章可省略 category，自动继承）
    icon: "A"
    author: ...
    description: 书库卡片上的简介
    tags: [龙头, 追涨]
articles:
  - id: asking-1-life
    title: "Asking ①：人物与经历——……"
    short_title: 人物与经历    # 系列导航/书库列表里显示的短标题（可选）
    series: asking
    order: 11                 # 系列内按 order 排序
```

- 书库：同系列合并成一张"X 系列（n 篇）"宽卡片，列出各篇（序号、短标题、摘要、时长、阅读进度），卡片顶部显示"已读完 k/n"。
- 文章页：标题下方显示系列导航（第 k / n 篇，当前篇高亮，手机端横向滚动并自动滚到当前篇）；底部"上一篇/下一篇"只在系列内跳转，不属于系列的文章仍在同分类的非系列文章之间跳转。
- 校验：系列 id 重复、缺 name、分类不存在、文章引用未登记的系列、文章分类与系列分类不一致都会报错；没有文章的系列不显示。
- 分类与扩展规划：短线游资/职业交易者放"前辈心法"（masters：养家、Asking、职业炒手、钙片、章盟主、赵老哥、小鳄鱼、退学炒股）；以企业价值为锚的长期投资放"价值投资"（value：巴菲特、芒格、段永平）；海外投机/交易经典放"海外交易经典"（classics：利弗莫尔）。没有文章的分类会在书库显示"待收录"，所以不提前建空分类。规划同时写在 `config/reading.yaml` 的 categories 注释里。
- 游资系列的材料分档：A 档为本人原帖（淘股吧博客帖子列表 + 发帖日期，可核对）；B 档为主流媒体基于龙虎榜的归纳和第三方整理稿；C 档为流传"语录"。C 档要单独辨伪，查不到原帖的标"待考"。
- 价值投资系列优先用一手资料（伯克希尔致股东信、股东手册、公开演讲），关键句中英对照并注明年份；查不到原始出处的流行语录单独列为"待考"。芒格只引演讲/问答原文；段永平引雪球与网易博客原帖（注日期与帖子编号），汇编本里找不到原帖的话标"待考"。
- 海外交易经典要区分本人著作与他人演绎：利弗莫尔只引其 1940 年的 *How to Trade in Stocks*；勒菲弗 1923 年的《股票大作手回忆录》是以他为原型的半虚构作品，引用时注明"勒菲弗笔下的 Livingston"；后人整理的术语（如"反转/持续关键点"）注明并非原书用语。
- 人物系列写作约定：开头 `::: summary` 一页读懂 + `::: note` 阅读说明与免责声明（不构成投资建议）；原话只做简短引用；传记信息标注"传闻/待考"；文末 `## 来源` 列出处链接。

## 拆分文章与旧链接跳转（redirects）

一篇长文拆成系列后，旧地址用 `redirects` 保留，书签和阅读进度不会失效：

```yaml
redirects:
  - from: chaogu-yangjia          # 旧文章 id（不能再出现在 articles 里）
    to: yangjia-1-overview        # 默认落地页
    parts: [yangjia-1-overview, yangjia-2-emotion, ...]   # 按原文顺序列出拆分后的各篇
    tasks_to: yangjia-6-practice  # 原文的勾选清单整体搬到了哪一篇（可选）
```

- 生成器写出 `output/reading/<from>.html` 跳转页（noindex，无 JS 时用 meta refresh 跳到 `to`），同时删除旧的图片目录。
- 带锚点（如 `#第-9-章-…`）访问时，跳到包含这个标题的那一篇，锚点保留。
- 不带锚点时，读取旧的 `rdProgress:<from>`，按各篇字数比例换算：已读完的篇记为 100%，正在读的那篇记录换算后的进度，并跳到这一篇（进度 3–97% 之间时；否则跳到 `to`）。
- `rdTask:<from>:i` 勾选状态迁移到 `rdTask:<tasks_to>:i`，只迁移一次（标记 `rdMigrated:<from>`）。所以 `tasks_to` 那篇的前 n 个复选框，要与原文的清单顺序一致。
- 校验：`from` 与现有文章重名、`to`/`parts` 里的 id 不存在都会报错。
- 图片：`content/reading/*/images/*.png` 已在 `.gitignore` 中放行，会随文章一起提交。

## 标注语法

| 写法 | 效果 |
|---|---|
| `::: core 标题` … `:::` | 提示框。类型：`core` 核心心法（红）、`tip` 解读（蓝）、`warn` 警示（橙）、`quote` 金句（青，衬线体）、`summary` 要点卡（金，编号圆点）、`note` 说明（灰）。标题可省略，省略时用类型名；可嵌套，框内可写任意 Markdown |
| 以 `💡` / `⚠️` 开头的段落或引用 | 自动套用 `tip` / `warn` 框，原文不用改（映射在 `emoji_map`） |
| `==重点句==` | 荧光笔高亮，可与 `**粗体**` 叠用：`==**…**==` |
| `[[术语]]`、`[[显示文字\|术语]]` | 术语气泡（桌面悬停、手机点按），释义取自术语表 |
| `glossary_auto: true` | 每个术语（含别名）在全文第一次出现处自动加气泡；标题、链接、图片说明里不加；提示框类型设 `auto_terms: false` 时框内不加（要点卡、阅读说明） |
| `> 引用` | 原文引用（衬线体灰底） |
| ```` ```mermaid ```` | 图示，前端渲染，可点「放大」 |
| `- [ ] 项目` | 可勾选清单，勾选状态保存在本机 |
| `<details>` / `<summary>…</summary>` | 折叠块（原样透传） |
| 独占一段的图片 + 紧随的 `*图 x：说明*` | 合成带图注的图片，点按放大 |

标注原则：只标关键处，补充强调和解释，不改写原文。
