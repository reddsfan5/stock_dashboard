# 34 · 阅读 / 心法板块

前辈心法、技巧、买卖逻辑等长文的阅读页。内容与配置入库，页面由生成器再生（`output/` 不入库）。

- 书库首页：<http://127.0.0.1:8765/reading.html>
- 文章页：`http://127.0.0.1:8765/reading/<id>.html`（首篇：`/reading/chaogu-yangjia.html`）
- 生成：`python -m scripts.reports.gen_reading`（日更 `refresh_apps` 与 `minute_viewer --serve` 启动时也会自动生成）

## 文件

| 路径 | 作用 |
|---|---|
| `config/reading.yaml` | 分类（前辈心法 / 技巧 / 买卖逻辑，可增）、提示框类型、文章列表 |
| `config/reading_glossary.yaml` | 共享术语表（释义、别名） |
| `content/reading/<id>/article.md` | 文章正文；图片放 `images/`，正文用相对路径引用 |
| `scripts/reports/reading_markdown.py` | 零依赖 Markdown 渲染器（含下述扩展） |
| `scripts/reports/gen_reading.py` | 生成书库页、文章页，复制图片到 `output/reading/<id>/` |
| `scripts/services/static/reading.{css,js}` | 排版、目录、进度、术语气泡、放大、mermaid 懒加载 |
| `scripts/services/static/vendor/mermaid/` | mermaid 11.17.2（本地托管，文章含图示时才加载） |
| `scripts/tools/qa_reading.py` | 登录后的浏览器回归（1440 / iPhone 13），截图到 `output/ui-qa/reading/` |

## 新增一篇文章

1. 建目录 `content/reading/<id>/`，放 `article.md` 和 `images/`（`id` 用小写字母、数字、连字符）。
2. 在 `config/reading.yaml` 的 `articles` 加一条：`id`、`title`、`category`（分类 id）、`author`、`summary`、`tags`、`order`、`glossary_auto`、`added`；`source` 省略时默认 `content/reading/<id>/article.md`。
3. 运行 `python -m scripts.reports.gen_reading`，刷新书库页。终端会提示找不到的图片、未闭合的提示框、术语表里没有的 `[[术语]]`。

新增分类：在 `categories` 里加 `id / name / icon / description`，顺序即书库分区顺序。

## 标注语法

| 写法 | 效果 |
|---|---|
| `::: core 标题` … `:::` | 提示框。类型：`core` 核心心法（红）、`tip` 解读（蓝）、`warn` 警示（橙）、`quote` 金句（青，衬线体）、`summary` 要点卡（金，编号圆点）、`note` 说明（灰）。标题可省略，省略时用类型名；可嵌套，框内可写任意 Markdown |
| 以 `💡` / `⚠️` 开头的段落或引用 | 自动套用 `tip` / `warn` 框，原文不用改（映射在 `emoji_map`） |
| `==重点句==` | 荧光笔高亮，可与 `**粗体**` 叠用：`==**…**==` |
| `[[术语]]`、`[[显示文字\|术语]]` | 术语气泡（桌面悬停、手机点按），释义取自术语表 |
| `glossary_auto: true` | 每个术语（含别名）在全文第一次出现处自动加气泡；标题、链接、图片说明里不加；提示框类型设 `auto_terms: false` 时框内不加（要点卡、阅读说明） |
| `> 引用` | 原文引用（衬线体灰底） |
| ```` ```mermaid ```` | 图示，前端渲染，可点「放大」 |
| `- [ ] 项目` | 可勾选清单，勾选状态保存在本机 |
| `<details>` / `<summary>…</summary>` | 折叠块（原样透传） |
| 独占一段的图片 + 紧随的 `*图 x：说明*` | 合成带图注的图片，点按放大 |

标注原则：只标关键处，补充强调和解释，不改写原文。
