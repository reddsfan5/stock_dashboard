# 17 — 市场口诀回测（前七条）

## 结论先行

使用本地日线缓存对 2018-01-01 至 2026-09-01 的沪深主板进行事件回测，
并要求信号日 20 日平均成交额不低于 5000 万元。在当前固定定义下：

- 第 2 条“连续大涨，赶紧离场”在 2018 年以来样本中得到支持；扩展到 2010 年后为部分支持；
- 第 7 条“急涨慢跌是出货”得到反向证据，当前定义下不支持；
- 第 1、3、4、5、6 条证据不足，不能作为独立买卖依据。

这不是说口语经验永远错误，而是说：在下面这套事先固定的阈值、股票池和持有期中，
大多数口诀没有表现出稳定、可独立使用的统计优势。

完整交互报告：`output/market_proverbs.html`

汇总数据：`output/market_proverbs_summary.csv`

近期事件核对：`output/market_proverbs_recent_events.csv`

## 统一回测口径

| 项目 | 口径 |
|---|---|
| 股票池 | 沪深主板代码，20 日平均成交额至少 5000 万元 |
| 信号时点 | 第 `t` 日收盘确认，所有条件只使用 `t` 日及以前数据 |
| 观察起点 | 下一交易日 `t+1` 的开盘价，避免用信号日收盘价假成交 |
| 观察终点 | 第 1、3、5 个交易日收盘；每条另指定一个主观察窗口 |
| 大盘对照 | 沪市股票对应上证指数，深市股票对应深证成指 |
| 超额收益 | 同一入场日和退出日的个股收益减指数收益 |
| 事件去重 | 同一股票条件连续成立时只记录第一次，避免同一段行情反复计数 |
| 置信区间 | 按信号日聚类计算超额收益 95% 区间，降低同日横截面共振造成的虚假精度 |
| 条件基线 | 大盘涨跌类与相同大盘状态比较，其余与全部流动性合格股票日比较 |

“支持”需要同时满足：

1. 主观察窗口的平均绝对收益方向符合口诀；
2. 平均超额收益方向符合口诀，且聚类 95% 区间不跨 0；
3. 口诀所说目标的命中率高于同条件基线。

只满足部分条件时标记为“部分支持”或“证据不足”。出现方向相反、超额区间也显著
反向、目标命中率还低于基线时，才标记为“不支持”。

## 七个回测项的量化定义

口语中的“小涨”“大涨”“横盘”“急涨”和“慢跌”没有唯一标准。本项目先采用以下
可复现定义；阈值全部集中在 `ProverbBacktestConfig`，可以做后续敏感性分析。

| 编号 | 口诀 | 信号定义 | 主窗口 | 目标命中定义 |
|---|---|---|---:|---|
| P01 | 一直小涨，会有大涨 | 连续 5 日每天涨 `0%～1.5%`，且 5 日累计至少 `2%` | 5 日 | 未来收益至少 `5%` |
| P02 | 连续大涨，赶紧离场 | 连续 3 日每天至少涨 `2.5%`，且 3 日累计至少 `8%` | 5 日 | 未来收益不高于 `0%` |
| P03 | 大盘跌，它横着走，会小涨 | 大盘当日跌至少 `1%`；个股近 3 日涨跌绝对值不超过 `1%`，区间振幅不超过 `3%` | 3 日 | 未来收益在 `(0%,3%]` |
| P04 | 大盘跌，它小涨，会大涨 | 大盘当日跌至少 `1%`；个股当日涨 `0.2%～2%` | 5 日 | 未来收益至少 `5%` |
| P05 | 大盘涨，它横盘，会小涨 | 大盘当日涨至少 `1%`；个股近 3 日涨跌绝对值不超过 `1%`，区间振幅不超过 `3%` | 3 日 | 未来收益在 `(0%,3%]` |
| P06 | 大盘涨，它小跌，会大跌 | 大盘当日涨至少 `1%`；个股当日跌 `0.2%～2%` | 5 日 | 未来收益不高于 `-5%` |
| P07 | 急涨慢跌是出货 | 先 3 日累计涨至少 `8%`；随后 5 日累计跌 `0.5%～6%`，至少 3 日收跌，且无单日跌超 `2.5%` | 5 日 | 未来收益不高于 `-3%` |

## 本次完整样本结果

### 怎样理解这些结果

P02 是唯一同时满足三层要求的口诀：连续急涨后的 5 日平均收益为负，平均超额收益
也为负，置信区间没有跨 0，而且“后续不涨”的命中率比无条件基线高 5.47 个百分点。
它更适合作为“降低仓位、提高止盈警觉”的风险信号，而不是保证下跌的机械卖点；仍有
约 41.75% 的样本后续收益为正。

P03 和 P05 的“小涨区间命中率”明显高于基线，但不能据此买入。横盘筛选本身就会把
后续收益压向 0 附近，因此更容易落入 `0%～3%` 这个狭窄区间；P03 的平均收益和超额
收益实际为负，P05 的绝对收益略正但超额略负。这正是同时查看均值、超额和条件基线的
必要性。

P07 在当前定义下出现了显著反向结果：慢跌结束后 5 日平均上涨 0.42%，平均超额上涨
0.28%，且超额区间完全高于 0。它更像“急涨后的有序回撤”，不能仅凭形态直接认定为
出货。若要继续研究出货，应加入成交量、换手率、筹码集中、长上影和大单资金等确认量。

P01、P04、P06 的点估计与口诀方向相反，但按信号日聚类后的不确定性仍较大，因此报告
采用“证据不足”而不是过度断言为永久失效。

### 全历史起点稳健性复核

另用同一套固定参数将起点扩展到 2010-01-01，且不覆盖主报告。各条方向基本保持：

- P07 仍然“不支持”：15,136 个样本，未来平均 `+0.47%`、超额 `+0.26%`，超额
  95% 区间为 `[+0.12%, +0.40%]`；
- P02 的未来平均收益仍为 `-0.51%`、超额 `-0.32%`、目标提升 `+4.67pp`，但超额
  95% 区间为 `[-0.64%, +0.001%]`，上沿刚刚跨 0，因此严格判定从“支持”降为
  “部分支持”；
- 其余五条仍未达到“支持”标准。

因此，第 7 条的反向证据对起点较稳健；第 2 条具有较强方向性，但严格显著性主要来自
2018 年以来的样本，实际使用应继续做分段验证，不能把它视为跨时代不变规律。

## 复现与调参

```bash
# 默认：2018 年至缓存最新日，20日平均成交额至少5000万元
python -m scripts.research.backtest_market_proverbs

# 扩展到缓存全历史
python -m scripts.research.backtest_market_proverbs --start 2010-01-01

# 提高流动性门槛到1亿元
python -m scripts.research.backtest_market_proverbs --min-amount 100000000
```

算法放在 `backtest/proverbs.py`，页面渲染放在 `backtest/proverb_report.py`，命令入口只
负责加载缓存、保存结果和刷新导航。要修改阈值，应修改或构造
`ProverbBacktestConfig`，不要把条件散落进脚本和页面。

## 下一轮值得做的稳健性验证

1. 将每个阈值上下移动 20%～30%，查看结论是否只在一个点成立；
2. 按 2018～2021、2022～2024、2025 至今分段，检查跨市场状态稳定性；
3. 按行业、市值和波动率分层，识别只在某类股票上成立的条件；
4. 对 P02 加入涨停无法卖出、滑点和手续费，转成真正的减仓策略回测；
5. 对 P07 加入量价背离和换手率条件，区分健康回撤与派发；
6. 做多组参数时进行时间留出和多重检验校正，避免在同一历史样本上挑最漂亮阈值。

## 限制

- 当前股票缓存无法提供历史时点的 ST 名称和完整退市股票清单，存在股票池幸存者偏差；
- 这是事件研究，不包含涨跌停排队、手续费、滑点和仓位竞争，不能直接当组合收益；
- 同一信号日的股票具有共同市场暴露，报告虽按日期聚类，但行业相关性仍可能残留；
- 阈值是对口语的一个工程化版本，不是口诀的唯一解释；
- 以上结论是历史统计关联，不构成投资建议。
