# 31 · 观察池收益监控

观察池的收益监控按“实际加入观察池日期”分批，而不是按筛出日分批。加入日期取 `watch_item.created_at` 转换到 `Asia/Shanghai` 后的本地日期；筛出日仍保留在明细中，便于复盘选股来源。

## 页面与入口

- 观察池：`http://127.0.0.1:8765/watchlist.html`
- 监控页：`http://127.0.0.1:8765/watchlist_monitor.html`
- 观察池页的“收益监控”按钮进入独立页面；它不占用主导航位置。

页面支持批次切换、日期范围、当前状态、来源模块和 1/3/5/10/20 个交易日窗口筛选。最新批次尚未出现下一个交易日时显示“等待入场”，不会用 0% 代替未知结果。

## 主动加入标的

观察池顶部的“加入观察”支持输入代码、简称或名称片段，例如 `600519`、`sh600519`、`茅台`。页面会从本地证券名称缓存实时列出匹配候选，点选后自动带入代码和名称；完整代码也可以直接提交。搜索只读本地缓存，不会触发行情更新或网络请求。

主动加入成功后会立即补算该条记录的 1/3/5/10/20 日窗口；每日更新仍会负责全量刷新和补齐历史结果。

## 收益口径

对加入日期之后的第一个真实交易日：

- 入场价：开盘价；
- 理论峰值：窗口内最高价相对入场价的涨跌幅；
- 窗口收盘：窗口最后一个可见交易日的收盘价收益；
- 最大不利：窗口内最低价相对入场价的跌幅；
- 超额收益：个股收益减去同期沪深 300 收益。

结果状态有 `pending`（等待入场）、`partial`（窗口尚未完整）、`complete`（窗口完整）和 `unavailable`（缺少行情）。理论峰值只表示曾经出现的价格空间，不代表能在最高点成交，也不模拟手续费、滑点、涨跌停排队和真实成交。

## 更新

```bash
python -m scripts.reports.gen_watchlist_monitor
python -m scripts.reports.gen_watchlist_monitor --rebuild
```

每日更新在 `watchlist_track` 后以非关键阶段执行 `watchlist_monitor`。监控失败不会阻断行情和观察池页面，失败原因会写入观察池监控元数据。

接口为当前登录用户隔离的只读查询：

```text
GET /api/watchlist/monitor
```

支持 `from`、`to`、`batch`、`horizon`、`status`、`source`、`sort`、`offset`、`limit`，页面只读取 SQLite 结果，不在首屏重新扫描日 K Parquet。
