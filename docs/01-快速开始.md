# 01 — 快速开始

## 环境要求

- Python 3.9+
- macOS / Linux（Windows 未充分测试）

## 安装

```bash
cd stock
pip install -r requirements.txt
```

核心依赖：

| 包 | 用途 |
|---|---|
| `akshare` | A 股数据源（K线、实时行情） |
| `pandas` | 数据处理 |
| `numpy` | 向量化计算 |
| `pyyaml` | 配置文件解析 |
| `tqdm` | 进度条 |
| `openpyxl` | Excel 行业分类文件读取 |

## 首次运行

### 1. 构建数据缓存

```bash
# 方式一：增量更新（首次会自动全量拉取，约 20-30 分钟）
python -m scripts.update_cache

# 方式二：代码调用
python -c "from data.kline import StockData; StockData().update()"
```

缓存与状态文件（角色说明，不绑定具体体积）：
- `cache/stock_kline_cache.parquet` — A 股日 K（排除北交所/科创板）
- `cache/etf_kline_cache.parquet` / `cache/index_kline_cache.parquet` — ETF 与指数日 K
- `cache/minute_kline_cache.parquet` — 股票与 ETF 的 1 分钟 K（每日增量积累）
- `cache/daily_basic_cache.parquet` — 估值/市值等日度快照
- `cache/stock_info.parquet` — 申万行业 1/2/3 级 + 名称
- `state/stock_journal.sqlite3` / `state/market_news.sqlite3` — 选股日记与市场资讯（个人数据）

### 2. 运行选股

```bash
# 运行全部选股模块，生成仪表盘
python -m scripts.screen
# → output/dashboard.html
```

### 3. 运行回测

```bash
# 运行全部回测策略
python -m scripts.backtest
# → output/stats_report.html
```

## 核心概念

### 选股 vs 回测 vs 模拟

```
选股 (Screen)    → 回答"今天哪些股票符合条件？"
                   基于最新数据，产出候选列表

回测 (Backtest)  → 回答"这个条件历史上胜率多少？"
                   全市场统计，产出成功率和收益分布

模拟 (Simulate)  → 回答"按这个策略操作，账户会怎样？"
                   资金约束下的真实交易流，产出权益曲线
```

### 重叠区（Overlap）

两日 K 线的重叠部分是本系统最核心的概念：

```
重叠区 = min(昨高, 今高) - max(昨低, 今低)
重叠率 = 重叠区 / 昨收 × 100%
```

- 重叠率 > 0：两日 K 线有交集，价格有连续性
- 重叠率 ≤ 0：出现跳空缺口
- 连续多日重叠 > 3%：价格企稳窄幅震荡，可能是变盘前兆

## 常用命令速查

```bash
# ── 数据维护 ──
python -m scripts.update_cache                         # 增量更新K线

# ── 选股 ──
python -m scripts.screen                               # 全部模块 → dashboard.html
python -m scripts.screen --only sideways,hammer        # 只看横盘+金针
python -m scripts.screen --refresh                     # 先更新缓存再跑

# ── 回测 ──
python -m scripts.backtest                             # 全部策略 → stats_report.html
python -m scripts.backtest --only overlap,rising       # 只看重叠+追涨
python -m scripts.backtest --start 2024-01-01          # 只看近两年

# ── 单股票调试 ──
python -m scripts.tools.debug_overlap --code sh600519        # 茅台逐笔信号
python -m scripts.simulations.sim_overlap --code sz002594          # 比亚迪资金模拟

# ── 交互 Web（8765）与静态报告（8000）──
python -m scripts.serve                                         # 一键启动两个 HTTP 进程
python -m scripts.serve start minute                            # minute/grid/trainer/journal/news 共用同一 web 进程
# http://127.0.0.1:8765/minute_view.html
# http://127.0.0.1:8765/grid_simulator.html
# http://127.0.0.1:8765/trading_trainer.html
# http://127.0.0.1:8765/stock_journal.html
# http://127.0.0.1:8765/market_news.html
# http://127.0.0.1:8765/watchlist.html
# http://127.0.0.1:8765/symbol.html?code=sh600519
# http://127.0.0.1:8765/daily_ops.html   # 或先 python -m scripts.reports.gen_daily_ops
python -m scripts.services.minute_viewer --code sh600519        # 仅生成一只股票的离线快照

# ── 全市场模拟 ──
python -m scripts.simulations.sim_portfolio                        # 组合模拟(原始版)
python -m scripts.simulations.sim_dip_buy                          # 组合模拟(回撤买入版)
python -m scripts.simulations.sim_dip_buy --capital 100000 -m 2.0  # 10万,2%止盈
```

分时页默认展示完整交易日；点击“动态分时”后会回到开盘，并在固定的全天时间轴上
逐分钟向右揭示价格、均价和成交量。可暂停、单步、调速、回到开盘或恢复全日视图。
网格回放、T+1 训练和选股日记中的内嵌分时也使用相同的按钮名称和播放心智模型。

## 输出文件一览

| 脚本 | 输出 | 内容 |
|------|------|------|
| `scripts/screen.py` | `output/dashboard.html` | 选股仪表盘（表格+K线弹窗） |
| `scripts/backtest.py` | `output/stats_report.html` | 回测报告（散点图+热力图+排名） |
| `scripts/tools/debug_overlap.py` | `output/overlap_debug.html` | 单股票逐笔信号分析 |
| `scripts/simulations/sim_overlap.py` | `output/overlap_sim.html` | 单股票资金模拟 |
| `scripts/serve.py start web` | `output/minute_view.html` 等 | 分时、网格、T+1 训练、选股日记、市场资讯共享交互服务 |
| `scripts/simulations/sim_portfolio.py` | `output/portfolio_sim.html` | 全市场组合模拟 |
| `scripts/simulations/sim_dip_buy.py` | `output/dip_buy_sim.html` | 回撤买入组合模拟 |

分时、网格、T+1 训练、选股日记和市场资讯需要保持交互 Web（8765）运行；其他 HTML 报告可直接打开，或由静态报告服务（8000）访问。每日 `update_cache` 是计划任务而非常驻服务。完整命令见
[`15-服务管理.md`](15-服务管理.md)。
