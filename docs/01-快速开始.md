# 01 — 快速开始

## 环境要求

- Python 3.9+
- macOS / Linux（Windows 未充分测试）

## 安装

```bash
cd stock
pip install -r requirements.txt
```

核心依赖：

| 包 | 用途 |
|---|---|
| `akshare` | A 股数据源（K线、实时行情） |
| `pandas` | 数据处理 |
| `numpy` | 向量化计算 |
| `pyyaml` | 配置文件解析 |
| `tqdm` | 进度条 |
| `openpyxl` | Excel 行业分类文件读取 |

## 首次运行

### 1. 构建数据缓存

```bash
# 方式一：增量更新（首次会自动全量拉取，约 20-30 分钟）
python scripts/update_cache.py

# 方式二：代码调用
python -c "from data.kline import StockData; StockData().update()"
```

缓存文件：
- `cache/stock_kline_cache.parquet` — 约 4400 只 A 股的日 K 线（开盘/最高/最低/收盘/成交额）
- `cache/stock_info.parquet` — 申万行业 1/2/3 级分类 + 股票名称

### 2. 运行选股

```bash
# 运行全部选股模块，生成仪表盘
python scripts/screen.py
# → output/dashboard.html
```

### 3. 运行回测

```bash
# 运行全部回测策略
python scripts/backtest.py
# → output/stats_report.html
```

## 核心概念

### 选股 vs 回测 vs 模拟

```
选股 (Screen)    → 回答"今天哪些股票符合条件？"
                   基于最新数据，产出候选列表

回测 (Backtest)  → 回答"这个条件历史上胜率多少？"
                   全市场统计，产出成功率和收益分布

模拟 (Simulate)  → 回答"按这个策略操作，账户会怎样？"
                   资金约束下的真实交易流，产出权益曲线
```

### 重叠区（Overlap）

两日 K 线的重叠部分是本系统最核心的概念：

```
重叠区 = min(昨高, 今高) - max(昨低, 今低)
重叠率 = 重叠区 / 昨收 × 100%
```

- 重叠率 > 0：两日 K 线有交集，价格有连续性
- 重叠率 ≤ 0：出现跳空缺口
- 连续多日重叠 > 3%：价格企稳窄幅震荡，可能是变盘前兆

## 常用命令速查

```bash
# ── 数据维护 ──
python scripts/update_cache.py                         # 增量更新K线

# ── 选股 ──
python scripts/screen.py                               # 全部模块 → dashboard.html
python scripts/screen.py --only sideways,hammer        # 只看横盘+金针
python scripts/screen.py --refresh                     # 先更新缓存再跑

# ── 回测 ──
python scripts/backtest.py                             # 全部策略 → stats_report.html
python scripts/backtest.py --only overlap,rising       # 只看重叠+追涨
python scripts/backtest.py --start 2024-01-01          # 只看近两年

# ── 单股票调试 ──
python scripts/debug_overlap.py --code sh600519        # 茅台逐笔信号
python scripts/sim_overlap.py --code sz002594          # 比亚迪资金模拟

# ── 全市场模拟 ──
python scripts/sim_portfolio.py                        # 组合模拟(原始版)
python scripts/sim_dip_buy.py                          # 组合模拟(回撤买入版)
python scripts/sim_dip_buy.py --capital 100000 -m 2.0  # 10万,2%止盈
```

## 输出文件一览

所有 HTML 报告均为自包含文件，可直接在浏览器中打开。
