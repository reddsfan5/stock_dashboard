## 第一类：超短线 T+1 — 赌次日涨跌

### 策略 1：超跌反弹 + 2% 止损

**逻辑**：连续 N 天下跌后市场有均值回归倾向，博一个小反弹。2% 止损控制尾部风险。

```
信号: 连续≥3天下跌 + 累计跌幅3~12%
买入: 次日收盘价, 半仓
卖出: +1%止盈 / -2%止损 / 尾盘强平
```

**结果**：-93%，2864 笔交易，胜率 49.9%

**亏损原因**：

1. **信号泛滥**：125,616 个信号（日均 200 个），大量劣质信号无法过滤
2. **连续下跌不是反弹信号**：A 股连续下跌更可能是趋势延续而非反转
3. **利润空间太小**：+1% 扣万六佣金后净赚不到 0.9%
4. **数学期望为负**：49.9% × 0.9% - 50.1% × 2% ≈ -0.55%/笔

---

### 策略 2：缩量横盘后放量突破

**逻辑**：经典技术形态——横盘缩量 = 筹码锁定，放量突破 = 主力启动。

```
信号: 前5天振幅<8% + 日均量<20日均量80%（缩量横盘）
      + 当天收盘>前5天最高 + 成交量>20日均量120%（放量突破）
买入: 次日收盘
卖出: +1.5%止盈 / -2%止损
```

**结果**：-38%，793 笔，胜率 42.7%

**亏损原因**：

1. **假突破多**：A 股很多"突破"只是一日游，第二天就跌回来
2. **无法区分有效突破和诱多**：纯量价过滤不够，需要更多维度（大盘环境、板块联动）
3. **突破失败后回撤往往超过 2%**：止损设太近

## 第二类：持仓多天 + 趋势跟踪

### 策略 3：均线多头排列

**逻辑**：均线多头排列 = 上升趋势确立，顺势而为。8% 止盈给利润足够空间。

```
信号: MA5 > MA10 > MA20 + 收盘 > MA5 + 近3日量增
买入: 次日收盘
卖出: +8%止盈 / -4%止损, 不限持仓天数
```

**结果**：-18%，398 笔，胜率 28.6%

**亏损原因**：

1. **均线多头排列是滞后信号**：等三条均线排好，股价已经涨了一段。此时买入 = 追高
2. **多数信号出现在趋势末期**：28.6% 胜率说明追在了阶段性高点
3. **8% 止盈在震荡市很难触及**：持仓变成温水煮青蛙，最终触发止损
4. **不止损不止盈的死扛也不对**：下跌趋势中的持仓会持续亏损

---

### 策略 4：超卖均值回归（迭代 3 次）

**逻辑**：跌到区间底部 + 当日收阳 = 支撑位反弹确认。反趋势策略。

```
信号: 收盘距20日最低<3% + 20日振幅10~35% + 当日收阳
买入: 次日收盘
卖出: +5%止盈 / -3%止损
```

**迭代过程**：

| 版本 | 入场条件 | 止盈 | 止损 | 胜率 | 收益 |
|------|----------|------|------|------|------|
| v4.1 | 距低点<3%+收阳 | +5% | -3% | 33.8% | -7.2% |
| v4.2 | 距低点<1.5%+收阳 | +5% | -3% | 33.8% | -7.2% |
| v4.3 | 距低点<1.5%+收阳 | +6% | -2.5% | 24.8% | -11.4% |

**结果**：最好 -7.2%，最接近打平

**几乎打平的原因**：
- 入场条件严格（三条件叠加），信号质量明显提升
- 3% 止损比 2% 更容忍波动

**仍然亏损的核心原因**：
- 胜率 33.8% 太低：支撑位在 A 股经常被打穿
- 5% × 33.8% - 3% × 66.2% ≈ -0.3% 期望，微负
- **关键洞察**：提高止盈会导致胜率进一步下降（v4.3），期望反而更差

---

### 策略 5：均值回归 + 5 天持仓限制

**逻辑**：v4 的改进——如果 5 天内既不止盈也不止损，主动退出。

**结果**：-10.9%，502 笔，胜率 36.5%

**亏损原因**：
- 胜率确实提升了（33.8% → 36.5%），但幅度不够
- 5 天到期强平 = 另一种止损，增加了亏损概率
- 均值回归在 5 天内不一定会发生

### 策略 6：ETF 动量 + 止损

**逻辑**：ETF 波动比个股小，动量策略更稳定。加止损控制风险。

```
信号: 每周一选近10日涨幅前5的ETF
持有: 5天
卖出: +5%止盈 / -3%止损 / 到期强平
```

**结果**：-16.7%，332 笔，胜率 32.5%

**亏损原因**：
- ETF 虽然比个股稳，但 5% 止盈对 ETF 仍然太高（一周涨 5% 罕见）
- 3% 止损频繁触发——ETF 的"小波动"也有 2~3%
- **核心问题依然是止损**：强制在亏损 3% 时卖出，不给均值回归机会

---

### 策略 7：月度多因子选股

**逻辑**：分散化 + 多因子 + 月度持有，减少个股噪声。

```
因子: 低振幅(30%) + 动量(25%) + 成交量(15%) + 距高点距离(30%)
选股: 综合得分前10只
持有: 20天
```

**旧版结果（待统一引擎重算）**：-21.5%

**亏损原因**：
- 股票层面的月度因子轮动在 A 股不赚钱
- 简单等权因子不如精细调优
- 选股范围太大（全市场 3000+），噪声淹没信号

## 第四类：找到盈利方案

### 策略 8：ETF 动量轮动

**关键转折**：去掉止损，让 ETF 的均值回归自然发挥作用。

```
信号: 近20日涨幅排名
选股: 动量最强的前 N 只 ETF
持有: M 天，到期全部卖出，重新排名
模式: 不止损、不止盈、纯粹跟随动量
```

**旧版参数扫描记录（待统一引擎重算）**：

| 持仓 | 3只 | 5只 | 10只 |
|------|-----|-----|------|
| 10天 | +107% / -82%回撤 | +69% / -60%回撤 | +41% |
| 20天 | +42% | +69% | +40% |
| **30天** | **+42% / -12%回撤** | **+60% / -12%回撤** | +31% |

**旧版阶段性推荐（待重算）：30 天 × 5 只**

```
总收益: +60%    年化: +13%
最大回撤: -12%   胜率: 53%
交易: 100笔     夏普: ~1.1
```

**对旧版结果的解释假设：**

1. **不止损是关键**：动量 ETF 的下跌往往是暂时的，持有足够长时间可以等回来
2. **ETF 不是个股**：没有暴雷风险，没有停牌，没有庄家操纵。下跌后能反弹
3. **月度频率过滤噪声**：日线噪声被 30 天窗口平滑，趋势信号更可靠
4. **集中持仓**：3~5 只而非 10 只，让最强的贡献更多收益
5. **最简单往往最有效**：只按涨幅排名，不过滤、不预测、纯粹跟随

**旧版扫描中为什么 30 天比 10 天好？**

- 10 天版本虽然总收益更高（+107%），但最大回撤 -82% 无法接受
- 30 天版本回撤只有 -12%，风险调整后收益更好
- 月度调仓 = 每月只需操作一次，实际可执行

## 核心教训

> 本节是旧版实验形成的研究假设。完成统一引擎全区间重算、样本外验证和费用压力测试
> 后，才能把其中内容升级为当前结论。

### 必须规避的

| 教训 | 说明 |
|------|------|
| **止损在 A 股短线是毒药** | 日波动 2~3% 是常态，-2% 止损几乎必然触发。止损赚不到趋势的钱，只赚到手续费 |
| **日线信号没有预测力** | 连续涨跌、横盘突破、振幅收窄——次日涨跌近乎随机，胜率顶多 50% |
| **过度优化适得其反** | 越加过滤条件，样本越少，过拟合越严重。v4 收紧条件后胜率反而下降 |
| **个股黑天鹅无法避免** | 单只股票可能暴雷、停牌、被操纵，量化策略在个股上风险极大 |

### 应该采纳的

| 经验 | 说明 |
|------|------|
| **持仓时间决定成败** | T+1 必亏 → 5天微亏 → 30天盈利。A 股的趋势在周/月级别才明显 |
| **ETF 比个股适合量化** | 指数基金没有个股风险，动量因子更纯粹 |
| **简单策略 > 复杂策略** | v8 只有一个条件："近 20 日涨幅排名"，其他策略最多有 5 个条件 |
| **不止盈不止损反而更好** | 让利润跑、让亏损通过时间回归。月度轮动自然地实现了这一点 |
| **分散化控制在 3~5 只** | 太少（1~2只）波动大，太多（10只）稀释收益。3~5 只最优 |
| **风险调整后收益才是关键** | 10天×3只表面+107%，实际回撤-82%不可能执行。30天×5只+60%且回撤-12%才是真策略 |

## 第五类：同花顺/散户经典战术

### 策略 9：缩量回调洗盘买入

**逻辑**：同花顺经典口诀——"放量涨缩量跌是洗盘，放量跌缩量涨是出货"。

```
信号: 10天前→5天前涨幅>3%（主力拉升）
     + 近5天回调3~12%（散户被洗出）
     + 近3天量缩至前段80%以下（确认缩量）
买入: 月频调仓日收盘价，等权5只ETF
卖出: 持有20天到期换仓，不设止盈止损
```

**旧版结果（待统一引擎重算）**：+71% 总收益，+15% 年化，-39% 最大回撤，70% 胜率，43 笔

**为什么能赚**：
- 缩量回调 = 洗盘信号，回调后继续上涨概率高
- 70% 胜率是所有策略中最高的
- 43 笔交易非常少（月均不到 1 笔），信号质量极高

**为什么回撤大**：
- 信号太少导致集中持仓风险
- -39% 回撤意味着在某些市场环境下会大幅亏损
- 适合作为策略 8 的补充，不宜单独重仓

---

### 策略 10：MACD 金叉 + 放量确认（❌ 亏损）

**逻辑**：最经典的指标组合——MACD 金叉 + 放量 = 主力入场信号。

```
信号: DIF上穿DEA（金叉）+ 当日量>5日均量1.2倍
买入: 月频调仓
卖出: 持有20天
```

**旧版结果（待统一引擎重算）**：-86%，110 笔，胜率 50%

**为什么亏**：MACD 金叉是滞后信号——金叉形成时趋势已经走了一大半。买入即买在阶段性高点，之后不是横盘就是回调。50% 胜率说明金叉和抛硬币没有区别。

---

### 策略 11：5/20 均线金叉（❌ 亏损）

**逻辑**：散户入门第一课——MA5 上穿 MA20 = 买入信号。

```
信号: MA5上穿MA20 + 收盘站稳MA5上方
买入: 月频调仓
卖出: 持有20天
```

**旧版结果（待统一引擎重算）**：-15%，115 笔，胜率 36%

**为什么亏**：均线的本质是价格的平均，天然滞后于价格。金叉时价格已经涨了一段，剩下的空间有限。36% 胜率说明多数金叉发生在上涨末期。

---

### 策略 12：放量突破 20 日高点（❌ 亏损）

**逻辑**：突破买入法——价格突破近期阻力位 + 放量确认 = 真突破。

```
信号: 收盘价>20日最高价 + 成交量>20日均量1.5倍
买入: 月频调仓
卖出: 持有20天
```

**旧版结果（待统一引擎重算）**：-10%，103 笔，胜率 46%

**为什么亏**：A 股假突破太多。突破 20 日高点后在震荡市会被迅速拉回，在熊市更是诱多陷阱。需要更大的量能（2 倍以上）和板块共振来确认。

## 第六类：因子投资策略

### 策略 13：强趋势缩量回调

**逻辑**：只在长期均线多头、接近年度高点的强势股票中，等待短期缩量回踩。

```
信号: 收盘>MA150>MA200 + 接近52周高点
     + 近5日回调0~8% + 成交额缩至20日均值70%以下
买入: 前一交易日确认，下一交易日调仓，等权
卖出: 持有20天
```

**设计动机**：避免在弱势股票中盲目抄底，只参与长期趋势仍向上的正常回调。

**结果**：待回测

### 策略 14：低波动强趋势

**逻辑**：在长期趋势向上的股票中，选择近20日振幅较低且动量较强的标的。

```
信号: 收盘>MA150>MA200 + 接近52周高点 + 20日振幅<15%
排序: 近20日动量由高到低
买入: 前一交易日确认，下一交易日调仓
卖出: 持有20天
```

**设计动机**：用长期趋势过滤方向，用低振幅减少急涨急跌和假突破噪声。

**结果**：待回测

### 策略 15：趋势强度排名

**逻辑**：不是简单地看"涨没涨"，而是看"涨得多有力"——MA5 对 MA20 的偏离度 + MA20 对 MA60 的偏离度。

```
信号: (MA5/MA20-1 + MA20/MA60-1) 综合得分前5
买入: 月频调仓
卖出: 持有20天
```

**设计动机**：纯动量（策略 8）看的是价格变化，趋势强度看的是均线结构——更平滑、更稳定。

**结果**：待回测

---

### 策略 16：双动量（绝对+相对）

**逻辑**：先过滤（绝对动量>0，确保在上涨趋势中），再排名（相对动量，选最强）。

```
信号: 近20日涨幅>0（绝对动量过滤）
     + 近5日×0.3 + 近20日×0.7 加权得分前5
买入: 月频调仓
卖出: 持有20天
```

**设计动机**：策略 8 的纯动量在全面下跌时会买入"跌得最少"的 ETF（仍然在跌）。绝对动量过滤确保只在上升趋势中持仓，熊市时空仓。

**结果**：待回测
