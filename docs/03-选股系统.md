# 03 — 选股系统

## 架构

```
screen/
├── base.py         # BaseScreener 抽象基类 + PipelineMeta 元信息
├── engine.py       # Screener 通用排序/过滤/导出引擎（管道模式）
├── continuity.py   # K线连续性选股
├── sideways.py     # 横盘震荡检测（100分综合评分）
├── trend.py        # 连续涨/跌趋势选股（含变体）
└── hammer.py       # 金针探底形态识别
```

所有模块遵循统一接口：定义 `PIPELINE_META` + `find_all(data, **kwargs)` → 返回 `pd.DataFrame`。

每个模块完成自己的形态筛选后，`features/snapshot.py` 会统一附加一份最新决策快照。
这避免了连续性、横盘、趋势等模块各自重复实现量比、ATR 或估值公式，也让所有选项卡
可以用同一口径横向比较。

## 网页上如何使用新增指标

运行 `python -m scripts.screen` 后，桌面版 `output/dashboard.html` 有三层信息：

1. 各策略选项卡保留原始选股理由，并附加指标日期、成交量/成交额比、换手、动量、
   市场相对强弱、ATR、年化波动、距高点回撤、动态 PE 和流通市值；表头悬停可查看口径；
2. 表格上方可按成交量比、换手率、20 日动量、ATR 上限和动态 PE 上限做二次筛选，
   表头仍可排序，适合从形态候选中进一步控制活跃度、趋势、风险和估值；
3. 点击代码打开 K 线侧栏，可集中查看全部决策指标，避免在主表中来回横向滚动。

手机版 `output/dashboard_mobile.html` 在候选卡片右侧只显示量比、换手和 ATR 三个高频
摘要；点击标的后再显示更完整的指标。网页只提供事实、比较和过滤，不把单个指标包装成
“买入建议”。常用组合思路如下：

| 目的 | 可先观察 | 主要防范 |
|---|---|---|
| 放量突破候选 | 成交量比、成交额比、20 日动量、相对强弱 | 量比高但成交额小、ATR 过大 |
| 横盘网格候选 | 换手、ATR、距 60 日高点 | 单边动量过强、流动性不足 |
| 超跌反弹候选 | 距高点回撤、动量、成交量比 | 只看跌幅、不等企稳或量能确认 |
| 容量与估值复核 | 成交额比、流通市值、动态 PE | ETF 无 PE；缺失值不应当作低估 |

`指标日期` 必须与本轮行情缓存最新交易日一致。供应商量比、动态 PE 和流通市值来自
独立日度快照，ETF 或数据源未覆盖的标的会留空，而不是用 0 代替。

工作日 18:30 的每日更新在数据质量门禁通过后，会依次重建整体行情/板块页面和完整
选股仪表盘，因此新增日线和日度基础快照会自动反映到网页。只想手工刷新选股页时运行：

```bash
python -m scripts.screen
```

## 一、通用选股引擎 (`screen/engine.py`)

管道模式，链式调用，不关心上游数据来源。

```python
from screen.engine import Screener

result = (Screener(df)
    .join_info()                              # 关联行业/名称
    .filter(sector="电力行业")                  # 行业过滤
    .sort(["综合评分"], ascending=[False])      # 按评分降序
    .head(50)                                  # 取前 50
    .to_csv("output.csv"))                     # 导出
```

### 支持的过滤条件

| 条件 | 方法 | 说明 |
|------|------|------|
| 行业 | `.filter(sector="电力行业")` | 支持申万1/2/3级 |
| 代码前缀 | `.filter(code_prefix="sh600")` | 只看沪市主板 |
| 最小成交额 | `.filter(min_amount=5000)` | 日均≥5000万 |
| 排序 | `.sort(["评分"], [False])` | 支持多级排序 |
| 行业分布 | `.sectors_breakdown()` | 申万1级统计 |

## 二、K线连续性 (`screen/continuity.py`)

**PIPELINE_META**: `{"id": "continuity", "title": "K线连续性"}`

### 选股逻辑

寻找价格有**连续性**的标的——每天最高价持续高于前日最低价一定比例，K线之间不出现大幅断裂。

```
条件：
  1. 仅沪深主板（排除创业/科创/北交所/ST）
  2. 近 N 天，每天 最高价 > 前一天最低价 + 前一天收盘价×min_gap%
  3. 近 N 天日均成交额 ≥ min_amount 万元

不要求K线实际重叠——允许向上跳空（今低 > 昨高），
只要今天最高价仍高于昨天最低价 min_gap% 以上，就认为有连续性。
```

### 筛选出的标的类型

- 稳步攀升的慢牛（每日小阳线、偶有跳空）
- 横盘震荡的平台（每日重叠）
- 上升通道中的回调再上涨

### 可配置参数

```yaml
continuity:
  min_gap_pct: 3      # 最小接续区%（越大越严格）
  strict: true         # true=K线必须重叠，不允许跳空
  min_amount: 5000     # 日均成交额下限（万元）
  lookback: 12         # 回看天数
```

## 三、横盘震荡 (`screen/sideways.py`)

**PIPELINE_META**: `{"id": "sideways", "title": "横盘震荡", "kwargs": {"days": 10}}`

### 评分体系（满分 100 分）

| 维度 | 权重 | 计算方式 |
|------|------|----------|
| 振幅 | 40% | 越小越好 — 价格波动收窄 |
| 趋势平坦度 | 25% | 线性回归斜率越平越好（无方向） |
| 重叠率 | 25% | K线重叠越高越好（筹码交换充分） |
| 区间位置 | 10% | 当前价在区间中部 |

### 可配置参数

```yaml
sideways:
  days: 10          # 回看天数
  max_amp: 15       # 最大振幅%
  max_slope: 0.5    # 趋势斜率上限
  min_overlap: 30   # 最小平均重叠率%
  r2_max: 0.3       # 线性R²上限（越小越无序）
```

### 适用场景

选出的标的特别适合做**网格交易**或**期权卖方策略**——在区间内反复收割。

## 四、连续涨跌 (`screen/trend.py`)

**PIPELINE_META**: 含两个变体

```python
PIPELINE_META = {
    "id": "trend",
    "variants": [
        {"id": "trend-up",   "title": "连续上涨(5日)", "kwargs": {"direction": "up"}},
        {"id": "trend-down", "title": "连续下跌(5日)", "kwargs": {"direction": "down"}},
    ]
}
```

### 选股逻辑

- **trend-up**：连续 N 天收阳 → 寻找强势股（过滤涨停连板妖股）
- **trend-down**：连续 N 天收阴 → 寻找超跌反弹机会

### 过滤规则

| 过滤项 | 默认值 | 说明 |
|--------|--------|------|
| 单日涨停 | 涨幅≥9.5% | 过滤一字板/连板妖股（trend-up） |
| 总涨幅上限 | 20% | 防止追高（trend-up） |
| 日均成交额 | 5000万 | 保证流动性 |

## 五、金针探底 (`screen/hammer.py`)

**PIPELINE_META**: `{"id": "hammer", "title": "金针探底"}`

### 形态定义

```
下影线 ≥ 实体 × 3     （经典锤子线标准）
实体/总振幅 < 20%      （实体越小越标准）
出现在近 3 日内
优先收阳（收盘 ≥ 开盘）
```

### 评分维度

| 维度 | 计算方式 |
|------|----------|
| 下影线/实体比 | 越大越好 |
| 探底深度 | 最低价在10日区间越低越好 |
| 成交量放大 | 金针日成交 > 前日成交 |
| 后续确认 | 金针日后有上涨 |

### 可配置参数

```yaml
hammer:
  min_shadow_ratio: 3    # 下影线/实体最小倍数
  hammer_days: 3         # 近 N 天内出现即可
  max_body_ratio: 0.20   # 实体/总振幅最大比例
  max_bottom_pos: 8      # 最低价在近期区间底部 N% 以内
  lookback: 10           # 回看天数
```

## 添加新选股模块

1. 在 `screen/` 下创建 Python 文件
2. 定义 `PIPELINE_META` 和 `find_all(data, **kwargs)`：

```python
# screen/my_module.py
PIPELINE_META = {"id": "my_module", "title": "我的选股", "kwargs": {"days": 10}}

def find_all(data, **kwargs):
    days = kwargs.get("days", 10)
    # ... 筛选逻辑 ...
    return result_df  # 必须包含 "代码" 列
```

3. （可选）在 `config/pipeline.yaml` 添加参数：

```yaml
my_module:
  days: 10
  threshold: 5.0
```

4. 运行即自动发现：

```bash
python -m scripts.screen --only my_module
```


## 观察池与次日跟踪（Phase 2）

选股仪表盘侧栏可「加入观察池」；独立页面：

```bash
python -m scripts.serve start watchlist
# http://127.0.0.1:8765/watchlist.html
```

| 路径 | 说明 |
|------|------|
| `state/watchlist.sqlite3` | 观察/待买/已买/放弃 + 次日跟踪结果 |
| `data/watchlist.py` | 仓储、`compute_next_day_return`、`rank_sector_strength` |
| `/api/watchlist/add` | 从筛出结果加入（status: watching/planned/bought/dropped） |
| `/api/watchlist/tracks` | 次日收益与「形态是否失效」（默认跌超 -3%） |
| `/api/watchlist/sectors` | 申万一级等权涨跌幅强度条 |
| 每日更新 `watchlist_track` | 非关键阶段，刷新跟踪结果 |

仪表盘 K 线侧栏按钮会调用交互 Web；需先 `python -m scripts.serve start web`。
