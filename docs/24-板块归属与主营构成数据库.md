# 板块归属与主营构成数据库

数据库：`state/classifications.sqlite3`，与训练、观察池等用户数据分开。该文件受现有 SQLite 忽略规则保护，不进入 Git；可从公开源重新同步，若要保留观察历史，应备份此库。

## 已接入数据

- 申万一、二、三级行业：从本地 `StockInfo` 档案导入，来源标记为 `shenwan`。
- 东方财富 F10 所属板块：逐标的获取，保留原始板块编号与名称，来源为 `eastmoney`。其列表混有行业、概念、地域、指数与风格标签，因此不统一误标为“概念”。
- 核心题材文本：保留源站说明，可在标的页展开查看。没有把文本擅自逐条配给概念标签。
- 主营构成：按报告期和产品、行业、地区分类保存收入、成本、主营利润及相关比例。源站小数比例乘 100 后存为百分数；缺失值保持 NULL，合法零值保持零。

## 页面与同步

标的上下文页新增“行业、概念与业务构成”；板块图谱新增同名数据商板块的已同步成分股，支持跳转标的。研究图谱的人工业务映射与数据商归属是两套有来源的数据，不互相覆盖。

访问标的页时先读本地缓存；缺少或超过 24 小时的资料通过后台队列更新，不阻塞现有标的工作流。用户可点“刷新资料”，一分钟内不会重复请求。同步出错保留最后成功数据及错误状态，不把空响应当成所有概念已退出来清库。ETF 不使用上市公司主营构成接口。

批量命令：

```sh
# 导入本地行业分类，并同步默认的三家商业航天示例及其财务分项
.venv/bin/python -m scripts.tools.sync_classifications
# 同步指定股票的板块、题材和财务分项
.venv/bin/python -m scripts.tools.sync_classifications --codes sh600118,sh600519
# 同步本地股票档案覆盖的全部标的板块；当天已成功同步者跳过
.venv/bin/python -m scripts.tools.sync_classifications --all --concept-only
# 如需全部标的主营构成，可显式运行全量同步（耗时更长）
.venv/bin/python -m scripts.tools.sync_classifications --all
```

这里的自动更新是“访问时检查缓存并后台同步”，不是新增定时任务。全市场批量更新按上述命令运行。

## 表与接口

- `security`：证券代码、名称。
- `board`：来源、源站板块编号、名称及分类口径。
- `membership`：标的—板块多对多关系，保存首次观察和观察结束时间、依据、来源链接。
- `segment`：报告期 × 分类维度 × 业务分项。
- `business_note`：源站核心题材说明。
- `sync_state`：每个标的、数据集的尝试时间、最后成功时间和错误状态。

只读：`GET /api/classification?code=sh600118`、`GET /api/classification/members?name=商业航天`。
触发后台同步：`POST /api/classification/sync`，JSON 包含 `code`、可选 `force`。

## 口径与限制

- 当前源站没有单列每个概念的收入贡献，界面显示“未披露（当前数据源未单列）”，不由主营构成自动推断。
- 成分反查明确标注已同步证券覆盖数，不承诺是源站完整实时成分表。当前返回最多 1000 条，若存在超过 1000 条的板块，应按分页进一步扩展。
- 财务报告期不是信息公开日期。关系的观察时间也不是概念实际纳入日期。
- 因缺少历史公告时间和历史板块快照，这些当前资料被排除在无剧透训练上下文之外；不能拿首次全量抓取结果回填过去。
- 数据源没有披露的业务维度、字段或响应失败，不填成零；源站返回的历史报告数量也可能有限。
