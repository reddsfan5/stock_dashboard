# 04 — 回测系统

## 架构

```
backtest/
├── engine.py   # 统计回测引擎：11 个策略 + 滑动窗口 + 统计分析
└── grid.py     # 网格交易回测：2 个策略 + 日内分钟线
```

两类回测定位不同：`engine.py` 回答"这个条件历史上胜率多少"，`grid.py` 回答"这笔钱做网格交易能赚多少"。

# 第一部分：统计回测引擎 (`backtest/engine.py`)

## 设计模式

```
StatsConfig（参数配置）
    ↓
WindowStats（模板方法基类）
    ├── _condition_matrix()  → 是否满足条件 (子类实现)
    ├── _calculate_outcome() → 收益计算 (子类实现)
    └── run()                → 滑动窗口遍历 (模板方法)
    ↓
StatsEngine（批量运行 + 汇总输出）
```

- **`StatsConfig`**：统一参数（连续天数、重叠阈值、目标收益、持有天数）
- **`DataPrepper`**：从缓存准备透视表（收盘价、最高、最低、日涨跌、K线重叠区%）
- **`WindowStats`**：抽象基类，子类只需实现两个方法，`run()` 是固定模板

## 回测流程

```
DataPrepper 准备数据
    │
    ▼
for 每只股票:
    for 每个交易日:
        if 连续 N 天满足条件:
            记录信号
            计算 N+1 买入 → N+M 卖出的收益
    │
    ▼
AnalysisResult（总样本、成功数、收益分布、多阈值统计）
```

## 策略详解

### 策略 1：连续重叠低买高卖 (`OverlapBuyStrategy`)

连续 N 天两日 K 线重叠区 > X%（默认 3%），说明价格企稳窄幅震荡。

```
条件: overlap_pct > X% 连续 N 天
买入: day[N+1].low （信号确认后次日最低价买入）
卖出: day[N+2].high（再次日最高价卖出）
收益: (sell - buy) / buy × 100%
```

### 策略 2：连续上涨追涨 (`RisingStreakStrategy`)

连续 N 天上涨后，次日是否继续涨。

```
条件: close > prev_close 连续 N 天
买入: day[N].close（N天收盘确认信号后追入）
卖出: day[N+1].close（次日收盘）
收益: (次日收 - 当日收) / 当日收 × 100%
```

### 策略 3：连续上涨创新高 (`RisingNewHighStrategy`)

连涨后未来 M 天能否创出新高，衡量追涨后的上行空间。

```
条件: close > prev_close 连续 N 天
参考: day[N].high
目标: 未来 horizon 天 max(high)
收益: (峰顶 - 参考高) / 参考高 × 100%
```

### 策略 4：连续重叠收盘买入 (`OverlapCloseStrategy`)

与策略 1 类似，但买入时机改为第 N+1 天收盘价——更贴近实际（收盘时执行）。

```
条件: overlap_pct > X% 连续 N 天
买入: day[N+1].close（收盘确认后买入）
卖出: day[N+2].high
```

### 策略 5：基准策略 (`BaselineStrategy`)

**无任何条件**，每天都对所有股票做"低买次高卖"，作为其余策略的**收益基准线**。如果某个策略跑不过基准，说明该条件信号反而有害。

```
条件: 无条件（永远 True）
买入: day[i].low
卖出: day[i+1].high
样本量: 最大（所有股票 × 所有天）
```

### 策略 6：放量/缩量上涨 (`VolumeUpStrategy`)

```
条件: close > prev_close AND 成交额日增/日减
买入: day[N-1].close
卖出: day[N].close
```

- `volume_increase=True`：放量上涨 → 主力资金推动
- `volume_increase=False`：缩量上涨 → 惜售、筹码锁定

### 策略 7：地量突破 (`VolumeDryUpStrategy`)

成交量缩至极低水平 → 变盘在即。

```
条件: vol < avg_vol(N天) × vol_ratio（默认 50%）
买入: day[i].close
卖出: 未来 horizon 天 max(high)
收益: (峰顶 - 收盘) / 收盘 × 100%
```

### 策略 8：跳空缺口回补 (`GapFillStrategy`)

```
条件: day[i].low > day[i-1].high（向上跳空）
回补: 未来 horizon 天 min(low) < gap_day_low
结果: 统计补缺概率（非收益）
```

### 策略 9：超跌反弹 (`OversoldBounceStrategy`)

```
条件: close < prev_close 连续 N 天
买入: day[N+1].low
卖出: day[N+2].high
```

### 策略 10：布林带收敛突破 (`BollingerSqueezeStrategy`)

布林带宽度缩至近期均值 70% 以下 → 大行情爆发前兆。

```
条件: BB_width < 过去N天BB_width均值 × 0.7
      BB_width = (2×σ) / MA
买入: day[i].close
卖出: 未来 horizon 天 max(high)
```

### 策略 11：多信号叠加 (`MultiSignalStrategy`)

K线重叠 > 3% **AND** 缩量（成交额日减），双重确认。

```
条件: overlap_pct > X% AND vol < prev_vol
买入: day[N+1].low
卖出: day[N+2].high
```

## 策略对比总览

| # | 策略 | 信号方向 | 持股 | 数据 |
|---|------|----------|------|------|
| 1 | 连续重叠低买高卖 | 震荡企稳 | 2天 | 全市场日线 |
| 2 | 连续上涨追涨 | 趋势追多 | 1天 | 全市场日线 |
| 3 | 连涨创新高 | 趋势追多 | M天 | 全市场日线 |
| 4 | 重叠收盘买入 | 震荡企稳 | 2天 | 全市场日线 |
| 5 | 基准（每天低买高卖） | 无信号 | 1天 | 全市场日线 |
| 6 | 放量/缩量上涨 | 量价配合 | 1天 | 全市场日线 |
| 7 | 地量突破 | 变盘信号 | M天 | 全市场日线 |
| 8 | 跳空缺口回补 | 缺口回补 | M天 | 全市场日线 |
| 9 | 超跌反弹 | 逆势反弹 | 2天 | 全市场日线 |
| 10 | 布林带收敛突破 | 波动率信号 | M天 | 全市场日线 |
| 11 | 重叠+缩量双确认 | 保守震荡 | 2天 | 全市场日线 |

# 第二部分：网格交易回测 (`backtest/grid.py`)

基于单只股票的**日内分钟级 K 线**，模拟网格交易。设计模式完善：

| 模式 | 位置 | 说明 |
|------|------|------|
| Strategy | `AbstractGridStrategy` | 两种网格策略可互换 |
| Template Method | `AbstractGridStrategy.run()` | 公共回测流程在基类 |
| Builder | `GridConfig` | 链式构建网格参数 |
| Value Object | `Bar`, `Trade`, `Position` | 不可变数据对象 |

## 公共概念

### 网格配置 (GridConfig)

```python
config = (GridConfig(base_price=10.0)
    .with_step(StepMode.PCT, 0.5)    # 每格 0.5%
    .with_levels(5)                    # 上下各 5 层
    .with_lot(100)                     # 每笔 100 股
    .with_price_range(8.0, 12.0)      # 有效区间
    .with_position_limits(0, 1500))   # 持仓 0~1500 股
```

| 参数 | 说明 |
|------|------|
| `step_mode` | `PCT`(百分比) 或 `DIFF`(固定差价) |
| `grid_step` | 每格步长 |
| `grid_levels` | 上下各 N 层 |
| `lot_shares` | 每笔基础股数 |
| `multiplier_levels` | 特定层倍数 `{3: 2}` = 第3层下2倍 |
| `price_floor/ceiling` | 有效价格区间 |
| `cage_to_market` | 超笼子转市价 or 废单 |

### 费率

```python
FeePolicy(commission=0.00025,    # 佣金 万2.5
          min_commission=5.0,    # 最低5元
          stamp_tax=0.0005)      # 印花税 万5（仅卖出）
```

### 回测流程（模板方法）

```
initialize → for bar in bars → check_triggers → execute → close_out
```

## 模式 1：成交驱动型网格 (`TransactionDrivenStrategy`)

### 核心逻辑

固定网格线挂单，收盘价**穿越**网格线即触发，触发后在对侧挂反向单。

```
初始: 基准价以下 All 层挂买单，以上 All 层挂卖单

上涨: 收盘从下向上穿越 G_lv → 触发卖单（G_lv价格成交）
      → lv-1 层挂买单（等回落接回）

下跌: 收盘从上向下穿越 G_lv → 触发买单（G_lv价格成交）
      → lv+1 层挂卖单（等反弹卖出）

超笼子: 价格超出有效区间 → 转市价 or 废单
```

### 适用场景

宽幅震荡市，价格在网格区间内反复穿越。每穿越一层收割一格差价。

---

## 模式 2：到价触发型网格 (`PriceTriggeredStrategy`)

### 核心逻辑

动态跟踪价格极值，以涨跌幅达到步长作为触发条件。

```
状态机: NEUTRAL ↔ UP（已卖等回落） ↔ DOWN（已买等反弹）

NEUTRAL + 下跌 step%  → 买入 → DOWN
DOWN    + 反弹 step%  → 卖出 → UP
UP      + 回落 step%  → 买入 → DOWN
DOWN    + 再跌 step%  → 加仓（倍数委托）

追踪极值:
  UP 状态: 跟踪 highest_since_sell → 回落 -step% → 买回
  DOWN 状态: 跟踪 lowest_since_buy → 反弹 +step% → 卖出
```

### 适用场景

趋势+震荡混合市。上涨时自动止盈追高，下跌时自动补仓。

---

## 两种网格对比

| | 成交驱动型 | 到价触发型 |
|---|---|---|
| 触发依据 | 收盘穿越固定网格线 | 从极值回撤/反弹达步长 |
| 网格 | 静态固定价格 | 动态跟踪高/低点 |
| 状态管理 | 每层挂单独立 | 全局状态机 |
| 连续同向 | 不支持 | 支持（多次加仓/减仓） |
| 适用市况 | 宽幅震荡 | 趋势+震荡混合 |
