## 一、模块自动发现 (`pipeline/runner.py`)

### 设计

扫描 `screen/` 目录，自动发现实现了 `PIPELINE_META` + `find_all` 的模块，无需手动注册。

```python
from pipeline.runner import discover_modules

modules = discover_modules()
# → [
#     PipelineModule(id="continuity", title="K线连续性", module="screen.continuity"),
#     PipelineModule(id="sideways",   title="横盘震荡",   module="screen.sideways"),
#     PipelineModule(id="trend-up",   title="连续上涨(5日)", module="screen.trend"),
#     PipelineModule(id="trend-down", title="连续下跌(5日)", module="screen.trend"),
#     PipelineModule(id="hammer",     title="金针探底",    module="screen.hammer"),
#   ]
```

### 模块变体

一个 Python 文件可以产生多个管线模块（通过 `variants`）：

```python
# screen/trend.py
PIPELINE_META = {
    "id": "trend",
    "kwargs": {"days": 5},
    "variants": [
        {"id": "trend-up",   "title": "连续上涨(5日)", "kwargs": {"direction": "up"}},
        {"id": "trend-down", "title": "连续下跌(5日)", "kwargs": {"direction": "down"}},
    ]
}
```

### 发现规则

- 文件位于 `screen/*.py`
- 排除 `__init__`、`base`、`engine`
- 必须导出 `PIPELINE_META` (dict) 和 `find_all` (function)

## 二、并行执行

```python
from pipeline.runner import run_all

results = run_all(data, modules)
# → {"continuity": DataFrame, "sideways": DataFrame, ...}
```

### 执行流程

```
ThreadPoolExecutor (N个模块 = N个线程)
    │
    ├── Thread 1: screen.continuity.find_all(data, **kwargs)
    ├── Thread 2: screen.sideways.find_all(data, **kwargs)
    ├── Thread 3: screen.trend.find_all(data, direction="up")
    ├── Thread 4: screen.trend.find_all(data, direction="down")
    └── Thread 5: screen.hammer.find_all(data, **kwargs)
    │
    ▼
for each result:
    自动关联 StockInfo：补充名称、申万1/2/3级
    打印: ✓ 横盘震荡: 237 只
```

### 关键特性

- **真正的并行**：每个选股模块跑在独立线程
- **tqdm 隔离**：每个线程分配独立进度条行号，避免输出交错
- **容错**：单个模块失败不影响其他模块
- **自动关联行业**：结果自动 merge 申万1/2/3级 + 名称

## 四、配置管理 (`pipeline/config.py`)

### YAML 加载

```python
from pipeline.config import load_config, apply_config

config = load_config("config/pipeline.yaml")
# → {"continuity": {"min_gap_pct": 3, ...}, "sideways": {...}}

modules = apply_config(config, modules)
# → 把配置注入各模块的 kwargs
```

### 注入机制

```
config/pipeline.yaml          PipelineModule.kwargs
┌──────────────────┐          ┌────────────────────┐
│ continuity:      │  apply   │ id: continuity     │
│   min_gap_pct: 3 │ ──────→ │ kwargs: {          │
│   strict: true   │          │   min_gap_pct: 3,  │
│   min_amount: 5k │          │   strict: true,    │
└──────────────────┘          │   ...              │
                              └────────────────────┘
```

模块默认参数 → YAML 覆盖 → 命令行可进一步覆盖（通过 `--only` 指定）
