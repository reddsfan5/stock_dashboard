# 05 — 模拟交易

## 定位

回测告诉你"信号历史上好不好"，模拟告诉你**"真金白银按信号操作，账户会怎样"**。

核心差异：

| | 统计回测 | 资金模拟 |
|---|---|---|
| 样本关系 | 独立（互不影响） | 受资金约束（买A就买不了B） |
| 资金 | 无限 | 有限，逐日回收再利用 |
| 手续费 | 无 | 含佣金+印花税 |
| 成交 | 以极端价成交 | 限价单/尾盘平仓 |
| 输出 | 胜率/收益分布 | 权益曲线/逐笔盈亏 |

---

## 一、单股票模拟 (`scripts/sim_overlap.py`)

对**单只股票**做全历史模拟跟踪。

### 运行

```bash
python scripts/sim_overlap.py --code sz002594                    # 比亚迪
python scripts/sim_overlap.py --code sh600519 --capital 1000000  # 茅台,100万
python scripts/sim_overlap.py --code sz002594 --start 2024-01-01 # 只看2024年后
```

### 交易规则

```
信号条件: 连续 ≥3 天重叠 > 2%
买入: 信号日最低价，买最大手数
卖出: 次日挂 +target% 限价单
      → 最高价触及目标 → 止盈成交 ✅
      → 未触及 → 尾盘收盘价卖出 ❌
费用: 佣金万1 + 印花税万5（卖）
```

### 输出

`output/overlap_sim.html`：权益曲线 + 每笔收益图 + 交易明细表

## 二、全市场组合模拟 (`scripts/sim_portfolio.py`)

全市场扫描 + 每日资金分配 + 次日平仓。

### 运行

```bash
python scripts/sim_portfolio.py                                  # 默认5万
python scripts/sim_portfolio.py --capital 1000000                # 100万
python scripts/sim_portfolio.py --overlap 2.0 --target 2.0       # 宽松条件,2%止盈
```

### 信号生成

```
全市场主板扫描:
  → 每日计算 K线重叠区% = (min(昨高,今高)-max(昨低,今低))/昨收×100
  → 找连续 3~10 天重叠 > 3% 的窗口
  → 信号触发日 = 连续重叠结束 + 2 天
```

### 每日模拟流程

```
for 每个交易日:
  ┌─ a. 平仓: 所有昨日持仓 → 今日卖出
  │     最高触及目标(+1%) → 止盈 ✅
  │     未触及 → 收盘价强平 ❌
  │
  ├─ b. 开仓:
  │     阶段1: 随机选 2 只信号股，各买最大手数
  │     阶段2: 剩余现金按价格从低到高，买到买不起最便宜一手
  │
  └─ c. 记录: 权益 = 现金 + 持仓市值
```

### 关键特征

- **持仓周期**：严格 1 天（次日必卖）
- **资金分配**：随机 2 只优先，低价填满
- **费用**：佣金万1 + 印花税万5（卖）

### 输出

`output/portfolio_sim.html`：
- 5 个统计卡片（总交易/胜率/总盈亏/期末/收益率）
- Chart.js 权益曲线 + 持仓数量柱状图
- 按月折叠的交易明细（✅止盈 / ❌尾盘 标注）

## 三、回撤买入模拟 (`scripts/sim_dip_buy.py`)

**本模块的核心创新**——解决"事后用最低价买入"的不真实问题。

### 与 `sim_portfolio.py` 的核心差异

| | sim_portfolio.py | sim_dip_buy.py |
|---|---|---|
| **买入价来源** | 当日最低价（不真实） | 历史回撤推导的限价 |
| **成交条件** | 无条件成交 | 当日最低触及限价才成交 |
| **买入依据** | 无 | 回看15天最大单日跌幅 |
| **资金分配** | 随机2只+低价填满 | 按跌幅降序，90%为止 |
| **止盈目标** | 固定+1% | 参数 `-m` 可配 |

### 运行

```bash
python scripts/sim_dip_buy.py                                    # 默认5万,1%止盈
python scripts/sim_dip_buy.py --capital 100000 -m 2.0            # 10万,2%止盈
python scripts/sim_dip_buy.py --overlap 4.0 --lookback 10        # 更严条件,10天回看
```

### 买入三关过滤

```
信号触发日 D
    │
    ├─ 第1关: D 往前回看 15 个交易日，找最大单日跌幅 max_decline%
    │         限价 = D日前收 × (1 - max_decline%/100)
    │
    ├─ 第2关: 当日最低价 ≤ 限价？
    │         NO  → 跳过该股，看下一只
    │         YES → 以限价成交，买最大手数
    │
    └─ 第3关: 当日资金用掉 ≥ 90%？
              YES → 停止买入
              NO  → 继续下一只（按最大跌幅降序排列）
```

### 卖出逻辑

```
次日:
  最高价 ≥ 买入价 × (1 + m%)  →  止盈卖出 ✅
  最高价 < 买入价 × (1 + m%)  →  收盘强平 ❌尾盘
```

### 举例

某股前收 10 元，过去 15 天最大单日跌 5%：
- 限价 = 10 × 0.95 = 9.50 元
- 今天最低 9.45 → 触及限价，9.50 元成交
- 今天最低 9.60 → 没跌到位，跳过换下一只

### 参数

| 参数 | 默认 | 说明 |
|------|------|------|
| `--capital` | 50000 | 初始资金 |
| `--target` / `-m` | 1.0 | 止盈目标 % |
| `--overlap` | 3.0 | 重叠区阈值 % |
| `--lookback` | 15 | 回看天数 |
| `--commission` | 1.0 | 佣金（万分之） |
| `--start-date` | 2024-01-01 | 回测起点 |

### 输出

`output/dip_buy_sim.html`：权益曲线 + 持仓变化 + 月度明细（含止盈率统计）
