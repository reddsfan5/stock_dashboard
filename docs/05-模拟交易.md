# 05 — 模拟交易

## 定位

回测告诉你"信号历史上好不好"，模拟告诉你**"真金白银按信号操作，账户会怎样"**。

核心差异：

| | 统计回测 | 资金模拟 |
|---|---|---|
| 样本关系 | 独立（互不影响） | 受资金约束（买A就买不了B） |
| 资金 | 无限 | 有限，逐日回收再利用 |
| 手续费 | 无 | 含佣金+印花税 |
| 成交 | 以极端价成交 | 限价单/尾盘平仓 |
| 输出 | 胜率/收益分布 | 权益曲线/逐笔盈亏 |

资金模拟的公共能力位于 `backtest/sim_engine.py`：策略只负责信号和每日开仓决策，
引擎统一负责平仓顺序、费用、逐日盯市、期末强平、绩效指标和报告。默认随机种子为
`42`；日 K 同时触及止盈和止损时默认按偏保守的 `stop_first` 处理。

> 兼容旧结果时最低佣金默认为 0。做实盘可行性评估时，应通过
> `min_commission` 填入账户真实规则。详细口径与未解决边界见
> [13-回测可信度与架构演进](13-回测可信度与架构演进.md)。

如果目标是手动练习进出场，而不是让策略自动跑完整历史，请使用
[14-T+1交易训练](14-T+1交易训练.md)。它逐分钟揭示分时和当日 K 线，并在服务端
执行 T+1 持仓锁定，避免页面提前拿到未来行情。

## 一、单股票模拟 (`scripts/simulations/sim_overlap.py`)

对**单只股票**做全历史模拟跟踪。

### 运行

```bash
python -m scripts.simulations.sim_overlap --code sz002594                    # 比亚迪
python -m scripts.simulations.sim_overlap --code sh600519 --capital 1000000  # 茅台,100万
python -m scripts.simulations.sim_overlap --code sz002594 --start 2024-01-01 # 只看2024年后
```

### 交易规则

```
信号条件: 连续 ≥3 天重叠 > 2%
买入: 信号日最低价，买最大手数
卖出: 次日挂 +target% 限价单
      → 最高价触及目标 → 止盈成交 ✅
      → 未触及 → 尾盘收盘价卖出 ❌
费用: 佣金万1 + 印花税万5（卖）
```

### 输出

`output/overlap_sim.html`：权益曲线 + 每笔收益图 + 交易明细表

## 二、全市场组合模拟 (`scripts/simulations/sim_portfolio.py`)

全市场扫描 + 每日资金分配 + 次日平仓。

### 运行

```bash
python -m scripts.simulations.sim_portfolio                                  # 默认5万
python -m scripts.simulations.sim_portfolio --capital 1000000                # 100万
python -m scripts.simulations.sim_portfolio --overlap 2.0 --target 2.0       # 宽松条件,2%止盈
python -m scripts.simulations.sim_portfolio --seed 42                       # 固定候选排序，可复现
```

### 信号生成

```
全市场主板扫描:
  → 每日计算 K线重叠区% = (min(昨高,今高)-max(昨低,今低))/昨收×100
  → 找连续 3~10 天重叠 > 3% 的窗口
  → 信号触发日 = 连续重叠结束 + 2 天
```

### 每日模拟流程

```
for 每个交易日:
  ┌─ a. 平仓: 所有昨日持仓 → 今日卖出
  │     最高触及目标(+1%) → 止盈 ✅
  │     未触及 → 收盘价强平 ❌
  │
  ├─ b. 开仓:
  │     阶段1: 随机选 2 只信号股，各买最大手数
  │     阶段2: 剩余现金按价格从低到高，买到买不起最便宜一手
  │
  └─ c. 记录: 权益 = 现金 + 持仓市值
```

### 关键特征

- **持仓周期**：严格 1 天（次日必卖）
- **资金分配**：随机 2 只优先，低价填满
- **费用**：佣金万1 + 印花税万5（卖）

### 输出

`output/portfolio_sim.html`：
- 8 个统计卡片（总交易/胜率/止盈率/总盈亏/期末/收益率/最大回撤/Sharpe）
- Chart.js 权益曲线 + 持仓数量柱状图
- 按月折叠的交易明细（✅止盈 / ❌尾盘 标注）

## 三、回撤买入模拟 (`scripts/simulations/sim_dip_buy.py`)

**本模块的核心创新**——解决"事后用最低价买入"的不真实问题。

### 与 `sim_portfolio.py` 的核心差异

| | sim_portfolio.py | sim_dip_buy.py |
|---|---|---|
| **买入价来源** | 当日最低价（不真实） | 历史回撤推导的限价 |
| **成交条件** | 无条件成交 | 当日最低触及限价才成交 |
| **买入依据** | 无 | 回看15天最大单日跌幅 |
| **资金分配** | 随机2只+低价填满 | 按跌幅降序，90%为止 |
| **止盈目标** | 固定+1% | 参数 `-m` 可配 |

### 运行

```bash
python -m scripts.simulations.sim_dip_buy                                    # 默认5万,1%止盈
python -m scripts.simulations.sim_dip_buy --capital 100000 -m 2.0            # 10万,2%止盈
python -m scripts.simulations.sim_dip_buy --overlap 4.0 --lookback 10        # 更严条件,10天回看
python -m scripts.simulations.sim_dip_buy --seed 42                          # 固定候选排序，可复现
```

### 买入三关过滤

```
信号触发日 D
    │
    ├─ 第1关: D 往前回看 15 个交易日，找最大单日跌幅 max_decline%
    │         限价 = D日前收 × (1 - max_decline%/100)
    │
    ├─ 第2关: 当日最低价 ≤ 限价？
    │         NO  → 跳过该股，看下一只
    │         YES → 以限价成交，买最大手数
    │
    └─ 第3关: 当日资金用掉 ≥ 90%？
              YES → 停止买入
              NO  → 继续下一只（按最大跌幅降序排列）
```

### 卖出逻辑

```
次日:
  最高价 ≥ 买入价 × (1 + m%)  →  止盈卖出 ✅
  最高价 < 买入价 × (1 + m%)  →  收盘强平 ❌尾盘
```

### 举例

某股前收 10 元，过去 15 天最大单日跌 5%：
- 限价 = 10 × 0.95 = 9.50 元
- 今天最低 9.45 → 触及限价，9.50 元成交
- 今天最低 9.60 → 没跌到位，跳过换下一只

### 参数

| 参数 | 默认 | 说明 |
|------|------|------|
| `--capital` | 50000 | 初始资金 |
| `--target` / `-m` | 1.0 | 止盈目标 % |
| `--overlap` | 3.0 | 重叠区阈值 % |
| `--lookback` | 15 | 回看天数 |
| `--commission` | 1.0 | 佣金（万分之） |
| `--start-date` | 2024-01-01 | 回测起点 |

### 输出

`output/dip_buy_sim.html`：权益曲线 + 持仓变化 + 月度明细（含止盈率统计）

| | sim_overlap.py | sim_portfolio.py | sim_dip_buy.py |
|---|---|---|---|
| 范围 | 单股票 | 全市场 | 全市场 |

## 四、周期轮动模拟（策略 07～14）

策略 07～14 已统一使用 `backtest/rebalance.py`，不再各自复制现金、费用、平仓和权益
计算循环。统一时序为：

```text
T-1 收盘后生成排名 → T 日收盘执行调仓 → 每个交易日按收盘价盯市
```

这修复了旧版只记录调仓日权益导致的回撤遗漏，也修复了策略 13、14 使用当日收盘指标
又按当日收盘成交的前视问题。原有命令保持不变，例如：

```bash
python -m scripts.strategies.strategy_08_etf_momentum --hold 30 --top 5
python -m scripts.strategies.strategy_13_pullback --hold 20 --top 5
```

所有轮动策略额外支持：

| 参数 | 含义 |
|---|---|
| `--commission-bps` | 佣金，基点 |
| `--sell-tax-bps` | 卖出税费，基点 |
| `--min-commission` | 单笔最低佣金 |
| `--slippage-bps` | 单边滑点 |
| `--price-tick` | 最小报价单位 |
| `--max-participation` | 单笔成交额占当日成交额上限 |
| `--reject-one-price-limit` | 拒绝一字涨停买入/一字跌停卖出 |

报告中的调仓退出、期末平仓会分开标记；拒单、缩量成交和原因保存在结构化结果的
`events` 中。
