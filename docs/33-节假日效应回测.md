# 33 — 国庆 / 中秋节假日效应回测

## 结论先行（样本 2017-01-01 ~ 2026-09-24，沪深300）

- 共识别 16 个休市事件：2017、2020、2023、2025 四年中秋与国庆合并为一次休市（各记 1 次，
  标签“中秋+国庆”）；其余 6 年各 2 次。其中 14 个已走完 T+20，2026 中秋处于“节前已知、
  未复牌”，2026 国庆尚未到来。
- **节前偏强、复牌偏高开，节后没有延续优势**。14 个完整事件：T0 当日均值 +1.08%（胜率 64%，
  基准 +0.02%），T1 跳空均值 +0.81%（胜率 64%，基准 −0.04%），节后 5 日均值 −0.00%、
  节后 10/20 日中位数分别 −1.33% / −0.64%，与基准无显著差异。
- **2024 年 9 月底政策行情主导均值**。剔除 2024 年两次后（n=12）：节前 5 日 +0.63%、
  T0 当日 +0.59%（胜率 67%）、T1 跳空 +0.05%、节后 10 日 −1.99%（胜率 42%）。
  即“节前小幅抢跑、节后偏弱”的形态更稳，跳空溢价主要来自 2024。
- **风险偏好**：剔除 2024 后，中证1000 / 中证500 节前 10 日平均跑输沪深300 1.76 / 1.08 个百分点，
  节后 10 日再跑输 2.17 / 2.00 个百分点（跑赢占比均仅 17%），复牌首日短暂跑赢（跳空跑赢占比 83%）。
  即“节前小盘去风险”存在，但“节后再风险”没有被数据支持，更像节后大盘风格占优。
  创业板指节前 5 日相对强弱接近 0（+0.07pp），全样本的正值来自 2024。
- 节前缩量不明显：沪深300 节前量比中位数 0.91，缩量占比 64%（基准 56%）；合并长假 4 次全部缩量。

## 方法

### 事件识别

1. `backtest/holiday_effect.py` 硬编码 2017~2026 中秋节当天与国庆 10-01 作为锚点，并附官方休市区间供核对。
2. 在交易日序列（指数缓存日期 + `cache/trading_calendar.parquet` 补未来日）中找锚点所在空档：
   T0 = 空档前最后一个交易日，T1 = 空档后第一个交易日；空档必须跳过至少一个工作日，否则报错。
3. 同一 (T0, T1) 的中秋与国庆合并为一个事件，类型“合并”，节日标签“中秋+国庆”。
4. 分组：国庆(单独)、中秋(单独)、合并、国庆(含合并)、全部休市、全部(剔除2024)。

### 指标（交易日计，T+1 即 T1）

| 指标 | 定义 |
|---|---|
| 节前10日 / 节前5日 | C(T0)/C(T−10)−1，C(T0)/C(T−5)−1 |
| T0当日 | C(T0)/C(T−1)−1 |
| T1跳空 / T1当日 / T1日内 | O(T1)/C(T0)−1，C(T1)/C(T0)−1，C(T1)/O(T1)−1 |
| 节后5/10/20日 | C(T+k)/C(T0)−1 |
| 窗口最大回撤 / 最大涨幅 | T−10..T+10 收盘序列的峰谷回撤 / 谷峰涨幅 |
| 节后10日最高 / 最低 | T1..T+10 盘中最高/最低相对 C(T0) |
| 节前量比 / 节后量比 | T−5..T0（或 T1..T+5）均量 ÷ T−25..T−6 均量（成交量口径，指数缓存无成交额） |
| 相对强弱 RS | 代理指数同窗口收益 − 主指数收益（百分点）；代理：创业板指、中证1000、中证500、科创50（2020 起） |

### 基准与显著性

样本期内每个交易日都当作 T0 计算同一套指标，得到无条件分布。汇总表给出节日组与基准的
均值、中位数、胜率（收益 >0 占比；量比 <1 占比）和均值差；p 值为自助抽样双侧近似，
基准窗口重叠且事件少，只作参考。

## 复现

```bash
# 默认：2017 至缓存最新日，沪深300，代理 sz399006,sh000852,sh000905,sh000688
python -m scripts.research.holiday_effect

# 指定起点、主指数、输出目录；--no-fetch 只用本地缓存
python -m scripts.research.holiday_effect --start 2017 --index sh000300 --out output/research/holiday_effect
python -m scripts.research.holiday_effect --no-fetch

# 单元测试
python -m pytest -q tests/test_holiday_effect.py
```

输出（`output/research/holiday_effect/`）：`holiday_events.csv` 逐事件明细、`holiday_summary.csv`
分组统计、`holiday_rs_summary.csv` 风险偏好统计、`holiday_paths.csv` 平均路径、
`holiday_current_state.csv` 当前位置、`holiday_effect_paths.png` 路径图、`holiday_effect_report.md` 报告。

每年只需：节前先 `python data/index.py --update` 刷新指数缓存，再在 `MID_AUTUMN` / `NATIONAL_DAY`
中补充新一年的锚点与官方休市区间后重跑。

## 数据来源与低频约束

- 沪深300、上证、创业板指、科创50：`cache/index_kline_cache.parquet`（`IndexData`，日常管线维护）。
- 中证500 / 中证1000 不在日常指数目录：首次运行经 `IndexData._fetch_ak`（腾讯日K）按
  **一年一请求、间隔 ≥1.5 秒** 补齐 2016 至今（每个指数 11 次请求），写入
  `cache/index_extra_kline_cache.parquet`；之后只增量补最新年份。已与本地 510500 / 512100 ETF
  日收益交叉核对（相关系数 0.988 / 0.989）。

## 限制

- 每组仅 4~5 个事件，均值容易被单一年份（2024）主导，应优先看中位数、胜率和“剔除2024”列。
- 基准窗口两两重叠，p 值偏乐观；未做多重检验校正。
- 指数只有成交量没有成交额，量比不是换手率口径。
