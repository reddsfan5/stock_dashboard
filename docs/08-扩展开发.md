## 二、添加回测策略

### 统计回测策略

继承 `WindowStats`，只需实现两个方法：

```python
# 在 backtest/engine.py 中添加
class MyStrategy(WindowStats):
    """我的回测策略"""

    def _condition_matrix(self, prep: DataPrepper) -> pd.DataFrame:
        """
        返回 bool DataFrame（行=股票, 列=日期）
        True = 当天满足条件
        """
        # 示例：当日收阳 AND 成交额大于前日
        return prep.is_up & (vol > vol.shift(1))

    def _calculate_outcome(self, prep: DataPrepper, code: str,
                           day_idx: int) -> Optional[float]:
        """
        计算收益%。day_idx = 买入日索引（第 N+1 天）
        返回 None = 无法计算（数据不足）
        """
        if day_idx + 1 >= len(prep.dates):
            return None
        buy = prep.close.loc[code].iloc[day_idx]
        sell = prep.high.loc[code].iloc[day_idx + 1]
        return (sell - buy) / buy * 100 if buy > 0 else None
```

### DataPrepper 提供的属性

| 属性 | 类型 | 说明 |
|------|------|------|
| `prep.close` | DataFrame | 收盘价（行=代码, 列=日期） |
| `prep.high` | DataFrame | 最高价 |
| `prep.low` | DataFrame | 最低价 |
| `prep.overlap_pct` | DataFrame | 每日重叠区 % |
| `prep.is_up` | DataFrame | 当日收阳 bool |
| `prep.codes` | list | 股票代码列表 |
| `prep.dates` | list | 交易日列表 |

### 注册策略

```python
# 在 scripts/backtest.py 的 ALL_STRATEGIES 中添加

    ("my_strategy", "我的策略",
```

## 五、设计原则

### 选股模块

| 原则 | 说明 |
|------|------|
| 单一入口 | `find_all(data, **kwargs)` 是唯一对外接口 |
| 自描述 | `PIPELINE_META` 声明 id/title/kwargs |
| 返回标准 | DataFrame 必须含"代码"列，其余列自由 |
| 无副作用 | 不修改 data 对象，不写文件 |

### 回测策略

| 原则 | 说明 |
|------|------|
| 模板方法 | 继承 `WindowStats`，只覆写两个方法 |
| 纯计算 | 策略不持有状态，不访问磁盘 |
| 可组合 | 多信号叠加通过 DataFrame bool 运算实现 |

### 模拟引擎

| 原则 | 说明 |
|------|------|
| 自包含 | 一个脚本 = 完整模拟流程 |
| 可重现 | 随机种子固定，参数全部 CLI 化 |
| 有输出 | 终端统计 + HTML 报告 |

## 六、设计模式分布

| 模式 | 位置 | 说明 |
|------|------|------|
| 模板方法 | `backtest/engine.py` `WindowStats.run()` | 固定流程，子类实现细节 |
| 模板方法 | `backtest/grid.py` `AbstractGridStrategy.run()` | 网格回测固定流程 |
| 策略模式 | `backtest/grid.py` | 两种网格策略可互换 |
| 管道模式 | `screen/engine.py` `Screener` | `.join_info().filter().sort().head()` |
| 自注册 | `screen/*.py` `PIPELINE_META` | `pipeline/runner.py` 自动发现 |
| Builder | `backtest/grid.py` `GridConfig` | 链式构建参数 |
| Value Object | `backtest/grid.py` `Bar/Trade/Position` | 不可变数据对象 |
| 工厂方法 | `backtest/grid.py` `GridBacktestEngine.create()` | 根据 mode 创建对应策略 |
