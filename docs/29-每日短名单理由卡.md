# 29 — 每日短名单理由卡

把选股命中、决策快照、板块强度、观察池状态拼成 **10～15 只**可读卡片（为何入选 / 主要风险）。  
是决策辅助，不是买卖建议。设计取舍见 [28-大改动设计日志 · 条目 3](28-大改动设计日志.md)。

## 入口

- 页面：<http://127.0.0.1:8765/shortlist.html>
- 每日操盘清单第 1 步也会链到此页
- JSON：`cache/daily_shortlist.json`

## 生成

```bash
# 需已有选股仪表盘
python -m scripts.screen
python -m scripts.reports.gen_shortlist

# 或随每日操盘一起生成（会尝试刷新板块强度）
python -m scripts.reports.gen_daily_ops
```

常用参数：`--limit 15`、`--user-id 1`（观察池用户）、`--skip-sector-refresh`。

## 卡片内容从哪来

| 字段 | 来源 |
|------|------|
| 形态命中 | `output/dashboard.html` 的 `TAB_CODES` |
| 名称/板块/量价估值 | 同页 `KLINE_META`（与仪表盘决策快照同源） |
| 板块强度 | `cache/sector_strength_snapshot.json` |
| 观察池 | `WatchlistService.list_items`（默认 user_id=1） |

默认排除「仅连续下跌」命中；同一板块最多 3 只。评分规则见 `scripts/reports/shortlist_cards.py`。

