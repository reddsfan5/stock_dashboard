# 29 — 每日精选

> 页面展示名称已统一为“每日精选”；文件名和内部 `shortlist` 路径保留，以兼容已有链接与自动化任务。

把选股命中、决策快照、板块强度、观察池状态拼成 **10～15 只**可读卡片（为何入选 / 主要风险）。  
是决策辅助，不是买卖建议。设计取舍见 [28-大改动设计日志 · 条目 3](28-大改动设计日志.md)。

## 入口

- 页面：<http://127.0.0.1:8765/shortlist.html>
- 侧栏 / 工作台导航「日常看盘 → 每日精选」
- 每日操盘清单第 1 步也会链到此页
- JSON：`cache/daily_shortlist.json`
- 历史数据库：`state/shortlist.sqlite3`
- 收益监控：从每日精选顶部“查看当日收益监控”进入，自动带入当前候选日期；监控页可切换到全部历史批次。

页面顶部的“历史候选”可按交易日切换，也可使用前一/后一交易日按钮。历史页读取的是当日保存的完整快照，不会用当前行情重新计算过去的排名和理由。

## 生成

```bash
# 需已有选股仪表盘
python -m scripts.screen
python -m scripts.reports.gen_shortlist

# 或随每日操盘一起生成（会尝试刷新板块强度）
python -m scripts.reports.gen_daily_ops
```

常用参数：`--limit 15`、`--user-id 1`（观察池用户）、`--skip-sector-refresh`。

每次生成都会以指标交易日为主键，把完整候选快照写入 SQLite。同一天重复运行会原子替换为最新结果；不同交易日会持续累积，因此日常更新管线无需增加额外命令。

## 收益监控

每日精选生成后会自动刷新收益监控。也可以单独运行：

```bash
python -m scripts.reports.gen_shortlist_monitor
python -m scripts.reports.gen_shortlist_monitor --rebuild  # 首次回填全部历史候选
```

监控默认跟踪每天全部精选标的。精选在收盘后生成，因此按**入选次日（买入日 D1）开盘价买入**，N 日窗口为 D1 起的 N 个交易日（1、3、5、10、20）。主指标是买入后可卖区间内曾达到的最高价收益，同时显示窗口末收盘收益、最大不利波动和相对沪深 300 的超额收益。

A 股 T+1：买入当天不能卖出，所以理论峰值**不含买入当天的最高价**，只取 D2…DN。1 日窗口没有可卖日，峰值显示 `—`，只看收盘。

### 如何理解页面数字

- **理论峰值**：`max(D2…DN 最高价) / D1 开盘 − 1`，表示买入后可卖区间内曾经出现的最大价格空间；不含买入当天，不代表能精准在最高点卖出。
- **窗口收盘**：`DN 收盘 / D1 开盘 − 1`，作为更保守的结果参考。
- **最大不利**：`min(D1…DN 最低价) / D1 开盘 − 1`，包含买入当天（当天已承担持仓波动）。
- **峰值/收盘超额**：扣除沪深 300 同口径收益（D1 开盘为基准、峰值取 D2 起）后的相对表现，用来区分个股选择和市场普涨。
- **等待入场 / 等待可卖日 / 观察中**：尚未出现 D1；只有 D1 行情、还没有可卖日（峰值为空）；或窗口尚未走完。都不会用 `0%` 冒充结果。
- **无法买入**：D1 开盘即达涨停价（含一字涨停）视为买不进，单独计数，不计入中位数和 +5% 命中率。涨停幅度按板块：主板 10%（主板 ST 在 2026-07-06 前为 5%）、创业板/科创板 20%、北交所 30%。

收益监控只使用本地日 K，不模拟手续费、滑点、盘中涨跌停排队和仓位约束（仅识别买入日开盘涨停）。它用于验证“候选是否给过机会”，不是买卖建议。

监控页可用“入选批次”按精选日期查看单批候选，支持较早/较新批次切换；批次表现表的日期也可直接筛选该批，“当日精选”链接返回入选依据。日期范围仍可用于跨批比较。候选明细支持按排名、理论峰值或窗口收盘收益排序；点击代码可进入标的上下文。

## 卡片内容从哪来

| 字段 | 来源 |
|------|------|
| 形态命中 | `output/dashboard.html` 的 `TAB_CODES` |
| 名称/板块/量价估值 | 同页 `KLINE_META`（与仪表盘决策快照同源） |
| 板块强度 | `cache/sector_strength_snapshot.json` |
| 观察池 | `WatchlistService.list_items`（默认 user_id=1） |

默认排除「仅连续下跌」命中；同一板块最多 3 只。评分规则见 `scripts/reports/shortlist_cards.py`。
