## 条目 1｜移动端图表长按 scrub 与分时 HUD 共享化

| 字段 | 内容 |
|------|------|
| 时期 | 2026-09-07 ～ 2026-09-12 |
| 范围 | 选股 K 线、分时页、选股日记、T+1 训练台；共享库 `chart-touch.js` / `minute-scrub.js` |
| 相关提交（节选） | `chart-touch` 接入系列；分时十字/顶条/右侧价；`minute-scrub` 抽取；训练台 `minute_points` tip；播放中不销毁 scrub（`339e7a1` 等） |
| 操作说明 | [22-界面优化与局域网访问 · 图表触摸手势](22-界面优化与局域网访问.md) |

### 1. 背景与动机

手机上用本地量化 Web 时，图表交互和同花顺等习惯冲突：

1. **默认就要能滑页**。ECharts 默认把触摸吃掉或轻易弹出 tip，列表/训练页很难滚。
2. **看数要「长按才出」**。平时滑动不挡；长按后再横向拖着看价，松手消失。
3. **分时还要比 K 线多一层 HUD**：十字跟手、顶部固定详条、Y 轴右侧即时价（白字红/绿底），且 scrub 时关掉 ECharts 轴标签以免抢对比度。
4. **多页重复实现会漂移**。选股、分时、日记、训练台各自抄一份手势，后面必不一致；用户明确偏好**尽早抽可复用模块**，并期望以后同类手势默认复用。

训练台还有两条「修出来的动机」：

- tip 绑到了不存在的 `minute_bars`，真实播放数据在 `minute_points` → 顶条一直空。
- 播放每推进一分钟就 `renderMinute` → **destroy 再 bind** scrub → 长按信息被周期性打断。

### 2. 目标（做成什么样算对）

| 目标 | 验收意象 |
|------|----------|
| 默认滚页 | 粗指针 / 窄屏上，未长按不弹 tip，页面可竖滑 |
| 长按 scrub | ≈320–350ms 进入；横向跟点；松手退出 |
| 分时 HUD | 十字跟手；顶条固定展示时间/价/%/高低/量/均价；右侧价贴 Y 轴，不跟手指左右跑 |
| 跨页一致 | 选股 K 线、分时、日记、训练台同一套手势语义 |
| 播放不打断 | 训练/日记分时在播放刷新时，长按 HUD 不被拆掉 |
| 桌面不退化 | 宽屏仍可用鼠标悬停 tip，不被手机手势绑死 |

### 3. 具体思路

分层两块，而不是「一个超级库包办一切」：

```text
chart-touch.js     → 手势生命周期（何时进入/退出 scrub、是否允许滚页、索引回调）
minute-scrub.js    → 分时专用 HUD（DOM 十字 / 顶条 / 右侧价），内部依赖 ChartTouch
页面模板 / viewer  → 只提供 getChart / getCount / getPoint / getPrevClose
```

**手势（ChartTouch）**

- 宿主默认 `touch-action: pan-y`；进入 scrub 后改为锁横向拖、防误滚。
- `bindLongPressScrub({ el, getChart, getCount, onIndex, ... })`：页面用闭包读最新 `state`，**不必每次数据刷新销毁监听**。
- 粗指针上平时关掉 ECharts content tip；scrub 时由页面决定是否还要轴指示。
- 桌面仍走 `mousemove` tooltip，与长按路径分开。

**分时 HUD（MinuteScrub）**

- `ensureWrap` 在图表外包一层 `minute-scrub-wrap`（训练台模板也可预置），HUD 节点挂在 wrap 上，避免改 ECharts 内部 DOM。
- `onIndex`：有点则填顶条；无点（训练未揭示分钟）则清空顶条，但**仍可画十字与右侧 Y 价**（右侧价来自 `convertFromPixel`，不泄露未播放收盘）。
- scrub 期间持续 `axisPointer.show: false`，避免和自绘十字叠两套。

**训练台 / 日记接线**

- `getPoint` 必须对齐真实字段：训练态用 `minute_points`（按 `tradingTimes()` 槽位对齐），不是臆造的 `minute_bars`。
- `renderMinute` 高频调用时：**已绑定则只 `refreshHosts()`，禁止 destroy+rebind**（与日 K 的 `bindTrainerDailyTouch` 同一模式）。日记侧同样加固。
- 改模板后需重生 `output/*.html`（服务读的是生成页），否则磁盘模板已改、浏览器仍吃旧逻辑。

### 4. 取舍

| 选择 | 不选 / 放弃 | 理由 |
|------|-------------|------|
| 手势库与分时 HUD 拆开 | 全部塞进 `chart-touch` | K 线只要 tip/轴指示；分时要自绘 HUD。拆开后 K 线页不背 DOM HUD 成本 |
| DOM 自绘十字 + 顶条 | 只靠 ECharts `axisPointer` + tooltip | 移动端轴标签对比度差、位置难控；顶条要「固定在图顶」而不是跟手指 |
| 右侧价钉在 Y 轴边 | 价签跟在手指旁 | 同花顺习惯：手指定 X，价看轴边；跟手价签易挡曲线 |
| 长按才进 scrub | 单击/悬停即看数（手机） | 保留滚页；避免误触刷 tip |
| 无点仍显示十字/轴边价 | 无 `getPoint` 就整段 HUD 空白 | 训练未播放分钟也能对位；不靠 series 取值防剧透 |
| 播放时保留单例 bind | 每帧 destroy 重建（旧实现） | 销毁会清 HUD、拆监听，表现为「信息总被打断」 |
| 闭包读 `state` | 每次刷新把数据拷进控制器 | 少一层同步；刷新只动 ECharts option |
| 先抽共享模块再铺页 | 每页先抄一份再以后合并 | 符合「跨页交互尽早复用」偏好，减少漂移 |

刻意不做或延后：

- 不把选股 K 线的「区间涨跌幅 / 前后标的」逻辑塞进 `minute-scrub`（那是 K 线面板语义）。
- 不在 scrub 库里做训练防剧透策略（仍由训练 API / `getPoint` 只返回已揭示点保证）。
- 不引入新前端框架；继续原生 JS + ECharts，与现有壳层一致。

### 5. 效果

- 手机上四类图表手势语义对齐：平时能滑，长按拖着看。
- 分时页 / 日记 / 训练台 HUD 一致：十字、顶条、右侧价；scrub 时无脏轴标签。
- 训练台 tip 在正确数据源下能显示已播放分钟；播放推进时 HUD 不再被刷新掐断（自动化：长按中连续 `renderMinute` 五次，`isActive` 与 tip 仍在）。
- 后续新图：手势接 `ChartTouch`；若是分时再接 `MinuteScrub.bind`，避免第三份复制。

### 6. 关键与排障

| 现象 | 优先怀疑 |
|------|----------|
| 改了模板但行为旧 | 未执行 `python -m scripts.services.trading_trainer`（或对应 `write_app`）重生 `output/` |
| 训练台顶条空、十字却在 | `getPoint` 字段是否仍指向错误数组；或当前 idx 尚未揭示 |
| 播放时长按闪断 | 是否又在 `render*` 里 `destroy` / 全量 `MinuteScrub.bind` |
| 图高塌掉 | wrap 与 `#chart` 的 height / order；高度应落在 wrap 上 |
| 桌面 tip 没了 | 是否误把粗指针分支套到桌面；桌面应仍走悬停 |

### 7. 后续可记

- 若其它回放页也「每帧重绑图表交互」，一律按「单例 + refreshHosts」审查。
- 若 HUD 还要加字段，只扩 `getPoint` 返回值与 `setTip` 模板，不动手势状态机。

## 条目 2｜取消训练态对其它功能页的浏览拦截

| 字段 | 内容 |
|------|------|
| 时期 | 2026-09-12 |
| 范围 | `training-context.js`、`minute_viewer.py` HTML 409；文档 22 |
| 相关专题文档 | [22-界面优化与局域网访问 · 训练时间边界](22-界面优化与局域网访问.md) |

### 1. 背景与动机

训练进行中若侧栏点开选股 / 操盘等，前端 toast + 后端 JSON 409「请结束训练后查看」。手机上表现为黑底一行 error JSON，打断正常浏览，体验差于「防剧透」收益。

### 2. 目标

训练未结束也能自由打开其它功能；仅在**主动带训练上下文**的日记 / 分时 / 标的 / 资讯链路上保留防剧透。

### 3. 具体思路

- 白名单页：继续改写 URL，带上 `training_session` 等。
- 其它 `.html` / `/`：去掉训练参数后正常跳转（进实时页），**不再** `trainingBlocked` / `preventDefault`。
- 删除服务端对「非白名单 HTML + training_session」的 409。
- 白名单内的 API 防剧透（`read_context`）与分时过期 409 **保留**。

### 4. 取舍

| 选择 | 不选 | 理由 |
|------|------|------|
| 其它页去参数进实时 | 继续硬拦 | 用户要浏览工具，不接受整站锁死 |
| 保留白名单防剧透 | 训练相关页也改实时 | 从训练跳日记/分时仍不能泄未来行情 |

### 5. 效果

训练中可打开选股、每日操盘等；不再出现该 JSON 错误页。训练链路内防剧透行为不变。
