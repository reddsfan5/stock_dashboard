# 14 — T+1 无剧透交易训练

## 一、用途

这个页面用于训练“在当时信息下做决定”，不是查看完整历史后寻找完美买卖点。模拟开始
后，日 K 只显示当前交易日之前的数据；当前日 K 由已经播放的分钟线实时合成。分时曲线
同样只向右推进，服务端不会把未来分钟价格提前返回给浏览器。

启动服务：

```bash
python -m scripts.serve start trainer
```

浏览器打开：

```text
http://127.0.0.1:8765/trading_trainer.html
```

导航页中的“T+1 无剧透交易训练”会自动跳到这个服务地址。

## 二、训练流程

1. 输入证券代码或名称，从本地分钟缓存选择标的；
2. 选择明确日期，或者使用“随机挑战”；
3. 设置初始资金、佣金、最低佣金和卖出税费；
4. 逐分钟、按 5 分钟或 15 分钟速度播放行情；
5. 从并列的“买入 / 卖出 / 条件单”入口打开交易弹窗，选择立即成交或限价委托，
   填写数量（交易理由与情绪标签选填）；
6. 播放到收盘后进入下一交易日，继续处理已有持仓；
7. 在“撤单管理”中统一处理待成交限价单和监控中的条件单；
8. 用委托记录复盘“当时看到了什么、为什么行动、是否遵守原计划”。

训练日期经过完整性门禁：至少 200 根分钟线，首根不晚于 09:35，末根不早于
14:55。残缺交易日不会进入日期列表或随机挑战。若指数分钟缓存有覆盖，可选日会与
A 股宽基分钟日期取交集，尽量让情境卡走 `source=minute`；交集为空时回退股票日期并提示。

## 三、T+1 与成交口径

- 买入数量必须是 100 股整数倍；
- 当天买入的份额计入总持仓，但显示为“锁定”；
- 只有买入日期早于当前模拟日期的份额才计入“可卖”；
- 不允许卖空，同日卖出锁定仓位会明确显示“T+1 锁定”；
- “立即成交”训练单按当前已经显示的分钟收盘价撮合，完成后不可撤销；
- 未到价的限价单进入“待成交”，限价买单冻结所需现金，限价卖单冻结对应可卖持仓；
- 限价买单在后续分钟最低价触及委托价时成交，限价卖单在最高价触及时成交；
- 正常触价按委托价成交；如果下一分钟直接跳空穿越委托价，则按对委托人更有利的开盘价
  成交，限价成交不额外叠加滑点；
- 限价单可设为“当日有效”或“本次训练持续有效”。待成交期间可撤，当日有效单在切换
  交易日前自动过期；撤销或过期都会释放冻结资源；
- 佣金、最低佣金、卖出税费和滑点由统一执行模型计算；
- 多次买入后卖出采用先进先出分配持仓成本。

ETF 通常与股票的税费规则不同。页面参数是模拟假设，不是券商费率承诺；训练前应按
自己的账户和标的类型修改。

## 四、条件单

条件单由服务端会话保存，前端关闭弹窗或页面刷新后仍会继续监控。支持：

- 股价上涨到或突破指定价格；
- 股价回落到或跌破指定价格；
- 相对昨收的日涨幅、日跌幅；
- 相对持仓均价的单独止盈、单独止损；
- 同一张保护单同时设置止盈和止损，任一条件先满足即卖出；
- “先跌后弹”的两阶段反弹买入；
- “先涨后落”的两阶段回落卖出。

反弹买入和回落卖出都有两个必要参数，不再从创建后立即只跟踪一个比例：

```text
反弹买入：创建参考价 → 下跌达到 X% → 跟踪新低 → 从最低点反弹 Y% → 买入
回落卖出：创建参考价 → 上涨达到 X% → 跟踪新高 → 从最高点回落 Y% → 卖出
```

创建参考价是提交条件单时已经显示的分钟收盘价。第一阶段使用后续分钟的最低价或最高价
判断是否达到，第二阶段使用分钟收盘价相对已跟踪极值判断反弹或回落。这样可以避免在只
有分钟 OHLC、没有分笔先后顺序时，错误假设同一分钟的最高点一定发生在最低点之后。

止盈止损按包含交易费用的持仓均价计算。双条件在同一分钟内同时满足时，因为分钟数据
无法知道高低点先后，模拟器采用风险优先口径，按止损分支触发。

可以选择“当日有效”或“本次训练持续有效”，监控中的条件单可以在记录区直接撤销，
也可以和普通限价单一起在“撤单管理”中统一处理。条件单不会预先冻结现金或持仓；
触发时才提交模拟委托，因此届时仍可能遇到资金不足、可卖数量不足或 T+1 锁定。可恢复
的账户约束会进入等待执行，其他撮合拒绝会保留失败结果和拒单记录，便于复盘。

保护性卖出条件触发时，如果持仓因为当日买入仍受 T+1 锁定，条件单不会再被永久标记为
失败，而是进入“已触发，等待执行”：

- “本次训练持续有效”的条件单在下一交易日持仓可卖后继续执行；
- “当日有效”的条件单仍会在收盘后过期，不跨日执行；
- 等待期间仍可从撤单管理手动撤销；
- 若可卖持仓被另一张限价卖单冻结，也会等待冻结资源释放后再执行。

即使页面按 5 或 15 分钟快进，服务端仍逐分钟检查条件，避免跳过中间触发点。价格条件
使用新揭示分钟的最高/最低价判断，反弹和回落使用已揭示极值与分钟收盘价判断；触发后
统一按该分钟收盘价近似成交。由于分钟 OHLC 不包含分笔先后顺序，这只是可解释的训练
撮合，不等同于券商柜台成交。

## 五、防剧透边界

防剧透由服务端状态机保证，而不是只在图表上把数据隐藏：

```text
完整分钟缓存（仅服务端）
        ↓ 每次推进 1/5/15 分钟
已揭示分钟 → 当日分时 + 合成当日 K
历史日 K ───────────────────┘
```

活动会话接口只返回已揭示分钟、当前部分日 K、历史订单和账户状态，不返回未来价格。
日 K 悬停提示中的“区间涨跌”同样遵守无剧透约束：从悬停蜡烛的开盘价计算到最后一根已显示蜡烛的当前可见收盘价，不读取后续分钟或未来交易日。
页面刷新后可以用会话编号恢复状态；服务重启后会话清空，需要重新开始。随机挑战只随机
日期，不会改变行情本身。

### 当前可见行情指标

训练页把行情指标与账户盈亏分成两个区域。指标卡片会随着分时播放更新，但只能读取当前
分钟及此前数据：

| 指标 | 训练时口径 | 可辅助观察 |
|---|---|---|
| 盘中量比 | 截至当前分钟累计量 ÷ 前 5 日同一分钟平均累计量 | 当前成交节奏是否异常 |
| 价格 / 已揭示均价 | 当前价相对当日已播放成交量加权均价的偏离 | 追高、弱于均价或重新站回均价 |
| 20 日动量 | 当前价格相对 20 个交易日前收盘价 | 中期方向背景 |
| ATR14 | 13 个历史完整日加当前已揭示日真实波幅，占当前价 | 止损距离和仓位是否匹配波动 |
| 20 日年化波动 | 历史收益加当前已揭示收益计算 | 风险环境是否扩大 |
| 距 60 日高点 | 当前价相对最近 60 个已知交易日最高收盘价 | 趋势位置与回撤深度 |
| 此前 20 日均换手 | 只取当前模拟日前的完整交易日 | 标的通常的交易活跃度 |

没有足够历史样本时显示“—”，不会用未来交易日补齐。当天最终换手率也不会提前显示，
因为分钟缓存中没有可在当时准确复算换手率所需的历史流通股本快照。指标是决策上下文，
不是自动信号；交易理由仍应记录触发条件、失效条件和计划仓位。

## 六、建议的训练方法

每次委托前，先在“交易理由”里写清楚：

- 入场依据是什么，在哪个价格或形态下证明自己错了；
- 计划持有多久，下一交易日是止盈、止损还是继续观察；
- 仓位为什么是 100 股、半仓或满仓；
- 当前决定来自趋势、支撑、量价还是情绪，避免事后重新解释。

复盘时重点比较计划与执行，不只看最终盈亏：盈利但违反纪律，不应算作高质量决策；
亏损但严格按事前规则退出，反而可能是一次合格训练。

## 七、市场情境

训练页右侧「模拟资讯 / 市场情境」切换页中，市场情境展示：

- **A 股宽基**（上证、深成指、沪深300、创业板指、科创50）：优先读取独立的指数分钟缓存，按当前模拟分钟截断，与个股分时同一防剧透时钟；无分钟时回退开盘价并标注「无分钟缓存·仅开盘」；
- **港股恒生**：腾讯 `hkHSI` 五日分时写入同一指数分钟缓存；有点时按上海 `as_of` 转香港当地时刻截断；
- **美股 / 韩国**：仍为日线，按当地收盘后才揭示当日点位，状态标明交易中 / 已收盘 / 未开盘 / 隔夜，不伪造全球同分钟同步。

腾讯五日分时窗口约 5 个交易日，靠每日增量积累；股票分钟可更长，故训练日对齐指数覆盖很重要。

接口：`/api/trainer/market-context?date=&as_of=`（也可带 `session_id`）。海外与指数分钟缓存通过每日更新非关键阶段 `market_context` 刷新：

```bash
python -m scripts.update_cache --only market_context
# 或单独：
python -m data.index_minute --update
python -m data.global_markets --update
```

## 九、训练闭环持久化（Phase 1）

训练过程中的**日计划、决策快照、心态标记与会话复盘**写入 SQLite，与行情 Parquet 分离：

| 路径 | 说明 |
|------|------|
| `state/training_sessions.sqlite3` | `training_run` / `day_plan` / `decision_snapshot` / `mindset_marker` |
| `data/training_sessions.py` | 仓储 API：`upsert_day_plan`、`add_decision`、`add_mindset_marker`、`build_review` |

要点：

- 买入/卖出决策可填写**交易理由**与**情绪标签**（选填；自信 / 恐惧 / 追涨 / 犹豫 / 后悔 / FOMO / 其他）；
- `context_json` 只保存 as_of 时刻可见摘要（`truncate_visible_context`），防剧透；
- 收盘或主动复盘时，`build_review` 汇总盈亏归因、计划遵守（`check_plan_violations`）与情绪时间线；
- 训练页接口：`/api/trainer/plan`、`/api/trainer/mindset`、`/api/trainer/review`。

相关辅助事实（每日非关键 `stock_facts` 阶段刷新）：

- `cache/trading_calendar.parquet` — `data/calendar.py` 交易日 / 半日市收盘时刻；
- `cache/daily_limit_facts.parquet` — `data/stock_facts.py` 由日 K 推导的涨跌停 / 停牌标记。

## 八、当前边界


1. 本地分钟缓存目前只保留近一段时间，训练跨度受缓存覆盖限制；
2. 一分钟 OHLC 不能还原分笔顺序、盘口深度和排队位置；
3. 立即成交以已显示分钟收盘价近似；限价成交只能依据分钟高低价判断是否触及，不能
   还原盘口排队和同一分钟内的价格路径；
4. 条件触发时间和实际委托成交时间在实盘中可能存在延迟，本页将二者近似为同一分钟；
5. 页面用于建立决策纪律，不代表模拟收益可以外推到实盘。
