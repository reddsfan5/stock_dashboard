# 板块图谱

入口：`http://127.0.0.1:8765/sector_atlas.html`；导航位于“研究复盘 → 板块图谱”。
首篇为商业航天，图片由用户提供，按全景、火箭、卫星、地面应用、载人与在轨设施排序。

## 新增与维护

- 内容：`content/sectors/*.json`。每篇独立描述定义、边界、产业链层级、图文章节、零部件和公司映射。
- 模板：`scripts/services/templates/sector_atlas.html`。
- 视觉与交互：`scripts/services/static/sector-atlas.css`、`sector-atlas.js`。
- 图片：`scripts/services/static/sector-atlas/<专题 id>/`；沿用本地静态资源映射，局域网离线阅读无需访问原始下载目录。
- 生成：`.venv/bin/python -m scripts.reports.gen_sector_atlas`。生成默认入口及 `sector_atlas_<id>.html`；新增专题后选择器自动收录。默认入口为商业航天。
- 交互服务启动时自动生成。8000 静态入口可直接阅读，股票链接由共享壳层转到 8765。

新增专题时复制商业航天的 JSON 结构并替换所有内容；图片文件名在 chapters 中指定。公司必须附官方业务依据，说明业务关联边界，不能把主题关联当作收入贡献或正式指数成分。

商业航天图片中的个别小字、编号及“利润重心”排名存在口径问题，原图保留，正文已添加逐图阅读说明。未来更新公司资料时同步更新资料核对日。

## 验收

Playwright MCP 运行 `scripts/tools/qa_sector_atlas.js`：1440、1024、390、360 宽度，图片加载、原图放大、Escape、焦点返回、公司筛选与空状态、标的代码跳转及 8000 资源兼容。所有检查只读。

产业资料没有历史版本，不应进入无剧透训练上下文。现有服务对带训练上下文的该页面请求保持拦截。
