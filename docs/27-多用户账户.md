# 27 · 多用户账户隔离

交互 Web（8765）现已整站登录。个人数据（观察池、选股日记、训练会话、假设、资讯影响记录）按 `user_id` 隔离；行情 Parquet / 选股结果 / 资讯正文仍共享。

## 默认约定

1. **网页自助注册**：登录页可切换「注册」；新用户默认 `member`。也可用 CLI 建号。环境变量 `STOCK_ALLOW_REGISTER=0` 可关闭网页注册。
2. **整站需登录**：未登录访问页面会跳到 `/login.html`；API 返回 401。
3. **历史数据归管理员**：首次启动会创建管理员 `xiaodong`，并把已有个人表行回填到该用户。

## 管理员引导

- 环境变量 `STOCK_ADMIN_PASSWORD`：若设置，首次创建管理员时使用它。
- 否则启动服务时会在控制台打印**一次性随机密码**（不写进仓库）。

```bash
# 迁移 / 引导管理员
python -m scripts.users migrate

# 列出用户
python -m scripts.users list

# 创建普通用户
python -m scripts.users create --username alice --password '至少6位'

# 创建管理员
python -m scripts.users create --username bob --password '至少6位' --admin
```

## 验证隔离

1. 用管理员登录，在观察池加一只股票。
2. 退出，用另一用户登录：观察池应为空；不能改对方条目。
3. `/api/health` 仍免登录（供 `scripts.serve` 探活）。

## 网页注册

打开 `/login.html`，点「注册」。注册成功后自动登录并跳转。

关闭网页注册（仍可用 CLI）：

```bash
export STOCK_ALLOW_REGISTER=0
python -m scripts.serve restart web --replace-conflicts
```
