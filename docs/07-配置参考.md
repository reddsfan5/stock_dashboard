# 07 — 配置参考

## 配置文件位置

```
config/pipeline.yaml
```

所有选股模块和回测策略的参数均可在此集中配置。修改后下次运行自动生效，无需改代码。

---

## 完整配置项

### continuity — K线连续性

```yaml
continuity:
  min_gap_pct: 3       # 最小接续区%（每天最高 vs 前日最低的差额/前收）
                       # 越大越严格，默认 3%
  strict: true         # true=必须K线实际重叠（不允许跳空）
                       # false=允许向上跳空（今低>昨高），但要求最高价接续
  min_amount: 5000     # 日均成交额下限（万元），过滤流动性差的标的
  lookback: 12         # 回看天数
```

### sideways — 横盘震荡

```yaml
sideways:
  days: 10             # 横盘检测回看天数
  max_amp: 15          # 最大振幅%（区间最高-最低）/最低
                       # 越小越窄幅，默认 15%
  max_slope: 0.5       # 趋势斜率上限（线性回归系数）
                       # 越小越平坦，0=完全水平
  min_overlap: 30      # 最小平均重叠率%（所有相邻日重叠率的均值）
  r2_max: 0.3          # 线性R²上限（拟合优度）
                       # 越小越好=越随机=越无趋势方向
```

### trend — 连续涨跌

```yaml
trend:
  days: 5              # 连续涨/跌天数
  max_gain: 20         # 总涨幅上限%（过滤连板妖股）
  min_amount: 5000     # 日均成交额下限（万元）
  filter_limit: true   # 是否过滤单日涨停（涨幅≥9.5%）
```

### hammer — 金针探底

```yaml
hammer:
  min_shadow_ratio: 3  # 下影线/实体最小倍数
                       # 经典锤子线标准 ≥2，默认 3（更严格）
  max_body_ratio: 0.20 # 实体/总振幅最大比例
                       # 越小实体越小，形态越标准
  max_bottom_pos: 8    # 最低价在近期区间底部 N% 以内
                       # 越小探底越深，默认 8%
  hammer_days: 3       # 近 N 天内出现金针形态即可
  lookback: 10         # 回看天数（判断探底位置区间）
  min_amount: 5000     # 日均成交额下限（万元）
```

## 回测参数

回测通过 `StatsConfig` 配置（在 `scripts/backtest.py` 或代码中设置）：

```python
from backtest.engine import StatsConfig

config = StatsConfig(
    condition_days=5,    # 连续 N 天满足条件
    lookahead_days=2,    # 向后看 M 天（N+1买入, N+M卖出）
    overlap_pct=3.0,     # 重叠区阈值 %（仅重叠类策略）
    min_amount=0,        # 最小日均成交额（万元），0=不过滤
    gain_pct=2.0,        # 目标收益 %（判断成功/失败的分界线）
)
```

命令行等价参数：

| CLI 参数 | StatsConfig 字段 | 默认值 |
|----------|-----------------|--------|
| `--condition-days` | `condition_days` | 5 |
| `--overlap-pct` | `overlap_pct` | 3.0 |
| `--gain-pct` | `gain_pct` | 2.0 |
| `--horizon` | (策略特有) | 5 |
