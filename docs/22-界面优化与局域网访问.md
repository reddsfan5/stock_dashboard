## 使用入口

本机：<http://127.0.0.1:8765/daily_ops.html>。

本次启动检测到的同一 Wi-Fi 入口：<http://192.168.1.63:8765/daily_ops.html>。换网络或 DHCP 地址变化后，以启动日志打印的地址为准。

```bash
# 默认仅本机访问
.venv/bin/python -m scripts.serve start web

# 已有服务时，显式重启到局域网模式
.venv/bin/python -m scripts.serve restart web --lan --replace-conflicts

# 查看实际监听模式
.venv/bin/python -m scripts.serve status

# 切回仅本机访问
.venv/bin/python -m scripts.serve restart web --replace-conflicts
```

`--lan` 使交互服务监听 `0.0.0.0:8765`。按照本期确认的偏好，没有添加账号或访问码；同网设备可直接操作观察池、训练和日记，使用范围为可信家庭网络。

8000 是本机静态报告兼容入口。它映射 `/assets/` 共享资源，进入交互页面时跳转当前主机名的 8765 端口，并保留查询参数。旧 `mobile.html`、`dashboard_mobile.html` 入口保留查询参数和锚点，转到响应式页面。

本机原有 `com.stock.web-server` LaunchAgent 已切换到兼容报告服务，配置源在 `scripts/launchd/com.stock.web-server.plist`；原配置备份为 `/tmp/stock-web-server-before-ui.plist`。该配置含本机绝对路径，迁移电脑时需要修改。

## 训练时间边界

训练页跳转日记、标的上下文、分时和资讯时，携带 `training_session`、`replay_date`、`replay_time` 和标的代码。服务端从训练会话已揭示的状态生成响应。

- 日 K 最后一根保留当前分钟形成的局部 OHLC；均线仅由可见日 K 计算。
- 分时页面的初始 HTML 和数据接口均使用可见分钟，当前日期列表不包含未来交易日。
- 日记使用既有 `source` 字段区分本次训练的案例，保留原有数据库结构与普通日记行为。
- 历史选股命中、观察池及假设若没有当时快照，训练上下文页明确说明暂不展示。
- 会话过期、模拟时钟已经推进或标的不匹配时，返回错误，要求从训练页重新进入；不会降级加载最新行情。
- 含最新行情的普通工具入口在训练上下文中不可直接打开。使用“新训练”退出当前训练上下文后恢复普通导航。

## 更新状态与指数显示

`GET /api/system/status` 返回状态、目标交易日、更新时间和阶段摘要，不返回原始错误消息、详情对象或堆栈。每日操盘加载、恢复焦点、手动刷新时读取；连接失败显示生成时快照或上次读取状态。

指数缺失、非有限或非正价格显示“暂无有效数据”；合法的 0% 涨跌幅保留。五个已配置指数已补齐配色，新增指数有确定性回退。行情概览、手机行情和热力图报告已从缓存重新生成。

当前缓存状态仍为 `failed`，目标交易日 2026-09-04。界面如实显示该状态。本期未修复数据源与覆盖率问题。
