# 网格交易：术语、参数设计与近 10 日优化

本文是项目中日内 T+0 网格功能的完整概念手册，适用于
`backtest/intraday_grid.py`、动态回放页和
`scripts/research/optimize_intraday_grid.py`。这里描述的是可解释的研究与模拟口径，
不是收益承诺，也不能替代券商适当性要求、交易规则或真实柜台成交结果。

若要逐项比较所有参数开关的优势、缺陷、相互作用和配置模板，继续阅读
[12-网格参数设计](12-网格参数设计.md)。

## 当前撮合版本：grid-v2

动态回放与参数优化器共用此版本；此前的收益和参数排名不可直接比较。优化输出默认
使用带 `grid-v2` 的文件名，已有结果不会覆盖。

- 初始基准到首个行情点、前收至开盘不插值。跳空按实际观察价处理一次，预埋限价可获价格改善。
- 挂单、成交、基准更新和新触发沿同一OHLC路径推进，成交后不重放此前路径。
- 报价单位默认0.001元，也可显式选择0.01元；行情必须符合所选单位。这不会启用T+1。
- 理论网格保留精度；下跌触发/买入限价向下对齐，上涨触发/卖出限价向上对齐；反弹向上、回落向下对齐。滑点成交向不利方向对齐。
- 触发价限价和排队限价均从后续行情事件开始撮合，同分钟后续路径可以成交；对手价仍假设立即整笔成交。
- 自动撤单按行情时间经过的分钟数计算，包含午间间隔；到期先撤后撮合。分钟内事件共用该分钟时间，不推测秒级成交时间。
- 成交驱动的数量倍数是固定数量放大研究设置；到价型倍数只使用当前观察价或已记录极值。
- 超笼子转市价暂不支持，启用时接口报错；有效期和次日基准不会形成跨日连续账户。

## 1. 先理解网格究竟在做什么

网格交易先选一个参照价格，再在它上下安排一组相邻价格：价格向下一格时买入，
向上一格时卖出，希望在反复震荡中赚取价格差。它把“低买高卖”写成机械规则，
优势是减少临场情绪，弱点是依赖震荡：单边下跌会持续加仓，单边上涨会持续减仓，
网格太密时收益还可能被费用、滑点和无效成交吃掉。

520500 是华泰柏瑞恒生创新药 ETF（QDII）。[上交所上市公告](https://www.sse.com.cn/disclosure/announcement/listing/c/c_20241226_10767291.shtml)
明确它从 2024 年 12 月 27 日上市起实施日内回转交易，因此可作为本项目的 T+0
研究标的。这里的“T+0”指当日买入的基金份额可以在当日卖出，不代表当天交易
必然盈利，也不代表任何 ETF 都支持 T+0。

## 2. 两种网格的真正区别

两种策略的网格价计算可以完全相同，所以价格曲线和买卖点在平稳行情中可能非常
接近。真正不同的是**什么时候向交易所报单、什么时候占用资券，以及触价后是否
一定成交**。

### 2.1 成交驱动型

生命周期是：

```text
创建条件单
  → 按基准价计算一买一卖两笔限价单
  → 两侧同时报单并冻结对应现金/份额
  → 某一侧全部成交
  → 撤销另一侧
  → 以成交价更新基准
  → 重新计算并双侧报单
  → 循环至收盘或条件单失效
```

[中国银河证券的官方说明](https://www.chinastock.com.cn/newsite/cgs-services/stockBroker/smartTrading.html)
明确描述了“双侧提交—一侧全成—撤另一侧—更新基准—再次双挂”的流程。它的核心
优势是委托已经在市场中等待，执行确定性通常较高；代价是买单占现金、卖单占份额，
未成交时也不能拿这些资券做别的交易。

项目模拟口径：预埋限价在分钟 OHLC 路径穿越网格价时整笔成交；成交后基准直接
变为成交价。由于没有盘口队列，不能模拟部分成交和排队优先级。

### 2.2 到价触发型

生命周期是：

```text
创建条件单
  → 只监控价格，不预先报单、不冻结资券
  → 最新价到达买入或卖出网格
  → 可直接触发，或继续等待反弹/回落确认
  → 条件满足后才提交委托
  → 委托立即成交、排队、撤单或失败
  → 按配置更新基准并继续监控
```

它的优势是触价前不占用现金和持仓；代价是“触发”只是开始报单，不等于“成交”。
快速行情里可能产生滑点，排队价也可能一直不成交。因此动态页面中的“待成交委托”
在选择触发价限价或排队限价、条件已触发而后续行情尚未成交时出现；对手价模式仍立即整笔成交。

### 2.3 为什么回放流程有时看起来一样

如果到价触发型同时满足以下条件，它会非常接近成交驱动型：

- 不启用累计反弹和累计回落；
- 触价后按对手价立即整笔成交；
- 成交后按网格价更新基准；
- 分钟行情缓慢穿越网格，没有跳空和排队。

要观察差异，可选择“排队限价”，或启用累计反弹/回落，再关注事件列表中的
“到价、报单、成交、撤单”时间是否分离。两者最根本的比较指标不是买卖点颜色，
而是冻结资券、触发到成交的延迟、未成交率、滑点和最终基准。

## 3. 网格价格与触发术语

| 术语 | 含义 | 本项目口径 |
|---|---|---|
| 初始基准价 / 锚点 | 第一次计算上下网格的参照价 | 优化器使用当日开盘价；动态页可手工指定 |
| 当前基准价 | 最近一次更新后的网格中心 | 每次成交或触发后按配置变化 |
| 买入网格 | 当前基准下方的下一买入条件价 | `基准价 - 差价` 或 `基准价 × (1-下跌比例)` |
| 卖出网格 | 当前基准上方的下一卖出条件价 | `基准价 + 差价` 或 `基准价 × (1+上涨比例)` |
| 固定差价 | 每格用固定金额表示 | 例如基准 1.430、差价 0.005，则上下格为 1.425/1.435 |
| 涨跌比例 | 每格用相对基准的百分比表示 | 例如 0.2% 表示上下约 0.2%，不是 20% |
| 合并设置 | 买卖两侧使用同一间距或数量 | 参数少、适合对称研究 |
| 分开设置 | 买卖两侧间距或数量不同 | 可表达偏多、偏空或库存再平衡 |
| 网格层 / 格数 | 从基准向某方向跨越的相邻网格数量 | 跳过多格时可用于倍数委托 |
| 到价 | 监控价格首次触及某个网格 | 只说明条件满足，不保证委托成交 |
| 触发价 | 条件单决定提交委托时观察到的价格 | 直接触发时通常等于网格价；反弹/回落时可能不同 |
| 委托价 | 实际向市场提交的限价 | 可取对手价近似、触发价或更保守的排队价 |
| 成交价 | 委托最终成交的价格 | 可能不同于网格价、触发价和委托价 |
| 跳格 | 一段行情一次跨过多个网格 | 分钟 K 线中较常见；真实逐笔可能是多次连续触发 |

固定差价和百分比不是审美选择。低价 ETF 的报价刻度相对影响很大：上交所 ETF
最低买卖单位为 100 份、最小价格变动单位为 0.001 元，见
[上交所 ETF 交易规则问答](https://www.sse.com.cn/assortment/fund/etf/question/c/c_20240118_5734754.shtml)。
当价格为 1.400 元时，一个报价单位已经约等于 0.0714%。如果比例网格算出
1.43257 元，真实报单必须按交易规则调整到有效价格；固定差价 0.002、0.003 等
天然更容易约束为 0.001 的整数倍。

## 4. 委托、成交与基准更新术语

| 术语 | 含义 | 需要注意 |
|---|---|---|
| 每笔委托 / 每格数量 | 每次触发计划买卖的份额 | ETF 买入通常按 100 份整数倍设计 |
| 对手价 | 买入取卖方报价、卖出取买方报价 | 成交快，但行情快速变化时有滑点 |
| 触发价限价 | 以触发时价格报限价单 | 价格可控，但可能排不到成交 |
| 排队限价 / 被动价 | 用更保守价格加入买一或卖一队列 | 可能改善价格，也可能长时间不成交 |
| 预埋委托 | 条件触发前已经在市场中的委托 | 成交驱动型的关键特征 |
| 条件单 | 券商侧监控规则，满足条件后发出普通委托 | 条件单触发时间可能不同于柜台接单时间 |
| 全部成交 | 委托数量全部撮合 | 银河成交驱动型以“一侧全部成交”作为重挂依据 |
| 部分成交 | 只有一部分数量成交 | 当前分钟回测不建模，是重要实盘偏差来源 |
| 待成交委托 | 已报单但尚未整笔成交的订单 | 到价型触发价限价和排队限价均可显示 |
| 撤单 | 取消尚未成交的剩余委托 | 成交驱动型撤反向单；到价型可超时自动撤单 |
| 废单 / 拒单 | 委托未被交易系统接受 | 可能由价格、数量、资券或风控规则导致 |
| 滑点 | 期望价与实际成交价的差异 | 到价触发后才报单时尤其重要 |
| 基准更新时间点 | 触发后更新，还是全部成交后更新 | 未成交时提前更新可能令基准与真实持仓脱节 |
| 基准更新价格 | 用网格价、触发价还是成交价作新基准 | 用成交价更贴近真实账面，用网格价更稳定 |
| 自动撤单 | 排队超过指定分钟数后取消 | 能释放资券，但可能错过随后成交 |
| 超价格笼子转市价 | 限价不满足价格保护时改用更激进价格 | 当前版本暂不支持，启用时接口报错 |

本项目默认到价型“全部成交后更新基准”，因为这是最容易让策略状态与真实持仓保持
一致的口径。若选择“触发后更新”，排队单最终没成交时仍会移动基准，这不是程序错误，
而是一种更激进、也更容易状态漂移的规则。

## 5. 反弹、回落和倍数委托术语

| 术语 | 含义 | 例子 |
|---|---|---|
| 累计反弹 | 跌破买入网格后不立刻买，记录最低价，反弹指定幅度才触发 | 网格 1.420，最低 1.415，反弹 0.002，则 1.417 触发 |
| 累计回落 | 突破卖出网格后不立刻卖，记录最高价，回落指定幅度才触发 | 网格 1.440，最高 1.445，回落 0.002，则 1.443 触发 |
| 极值 | 进入跟踪状态后的最低价或最高价 | 极值继续刷新时，反弹/回落目标同步移动 |
| 反转确认 | 价格离开极值达到设定幅度 | 试图避免在快速单边走势中过早接刀或卖飞 |
| 保底价触发 | 正常反转目标越过原网格时，最迟在原网格触发 | 防止确认幅度过大导致条件长期无法满足 |
| 倍数委托 | 一次跳过多格时按格数放大委托数量 | 跳过 3 格可下 3 倍数量，但受最大倍数和持仓限制 |

反弹/回落不是无条件提高胜率。确认值太小，与直接到价几乎相同；太大则会错失 V 型
反转，或者让基准长时间无法更新。一般先让确认值处于一个网格间距的 20%～50%，
再通过逐笔级数据检查触发质量；这只是搜索起点，不是固定答案。

## 6. 账户、持仓与价格边界术语

| 术语 | 含义 | 为什么重要 |
|---|---|---|
| 现金总额 | 账户当前现金 | 已冻结现金仍属于总额 |
| 可用现金 | 当前还能用于新委托的现金 | 成交驱动型通常小于现金总额 |
| 总持仓 | 当前持有的全部基金份额 | 含被卖单冻结的份额 |
| 可用持仓 | 当前还能卖出或用于新卖单的份额 | 总持仓减冻结持仓 |
| 初始仓位比例 | 启动时证券市值占总资产比例 | 对称网格通常需要同时留现金和底仓 |
| 保留底仓 / 最小持仓 | 策略不得卖出的最低份额 | 防止连续上涨时完全空仓 |
| 最大持仓 | 策略允许持有的最高份额 | 防止连续下跌时无限补仓 |
| 有效价格区间 | 只在上下限内生成网格或委托 | 把策略约束在研究认为有效的震荡区间 |
| 持仓控制 | 保留底仓、最大仓位及可用资券的总称 | 是网格的首要风险约束，不是附属参数 |
| 冻结资券 | 已提交委托占用的现金或份额 | 成交驱动型双挂时同时冻结两侧 |
| 库存漂移 | 期末仓位比例偏离期初仓位比例 | 漂移大意味着多日连续运行会改变风险暴露 |
| 账户净值 | 现金 + 持仓 × 当前价 | 评价总收益和回撤的基础 |

“账户状态”若已在曲线上方状态条完整呈现，页面不必再做一套重复卡片；但字段本身仍然
是策略判断现金不足、不可卖和冻结资券的必要状态。

## 7. 跨日、监控和有效期术语

| 术语 | 含义 | 当前模拟边界 |
|---|---|---|
| 监控行情 | 条件单用哪种价格判断到价 | 可用分钟 OHLC 路径或仅分钟收盘价 |
| 分钟 OHLC 路径 | 用开、高、低、收推测一分钟内先后 | 阳线按 O→L→H→C，阴线按 O→H→L→C |
| 分笔 / Tick 数据 | 每一笔成交或更细粒度报价 | 比分钟线更适合判断触发顺序与滑点 |
| 盘后更新基准 | 收盘后把下一日基准改成指定价格 | 单日页面只显示下一日基准，不跨日虚构成交 |
| 次日基准价更新 | 新交易日开始时重新锚定网格 | 需决定用昨收、今开、最新价还是前日成交基准 |
| 有效期 | 条件单允许持续监控的自然日数 | 属于券商条件单管理，不等于回测样本长度 |
| 交易日 / 自然日 | 有行情的开市日 / 日历上的每一天 | “近 10 天”优化器取最近 10 个有数据交易日 |

## 8. 收益与风险指标术语

| 指标 | 定义 | 解读 |
|---|---|---|
| 总收益 | 期末净值减期初净值 | 含标的本身涨跌和网格交易效果 |
| 持有基准 | 不做网格，保持初始份额到收盘 | 用来隔离标的当天上涨或下跌的影响 |
| 超越持有 | 网格期末净值减持有基准净值 | 本优化器的主要比较指标 |
| 已实现盈亏 | 已卖出份额对应的交易盈亏 | 不包含仍持有库存的浮动盈亏 |
| 未实现盈亏 | 期末持仓按收盘价计价的浮盈亏 | 可能在下一日反转或继续扩大 |
| 最大回撤 | 净值从此前峰值到随后低点的最大跌幅 | 同时受市场方向和策略仓位影响 |
| 超额回撤 | 相对持有的超额曲线从峰值的最大回落 | 更适合比较同一标的不同网格参数 |
| 换手率 | 当日成交金额合计 / 期初净值 | 过高通常意味着费用和执行误差上升 |
| 正超额日占比 | 超越持有大于 0 的交易日比例 | 样本少时只能作描述，不能当稳定概率 |
| 最差超额 | 样本中单日最低超越持有收益率 | 用于约束尾部，而不只看平均值 |
| 训练段 | 用于选择参数的较早日期 | 本脚本默认前 7 日 |
| 验证段 | 不参与排序、只检验外推的较晚日期 | 本脚本默认后 3 日 |

## 9. 参数设计：从约束开始，不从“最优收益”开始

### 9.1 第一步：确认交易制度

先核对标的是否允许日内回转、买卖单位、最小报价单位、涨跌幅限制、停牌与溢价风险。
上交所说明跨境 ETF 等部分品种支持 T+0，但普通境内股票 ETF 通常是 T+1，见
[ETF 常见问题](https://www.sse.com.cn/assortment/fund/etf/question/)。代码前缀或名称不能
替代交易所公告核验。

### 9.2 第二步：让一格覆盖交易摩擦

完成一次“买入—卖出”的净捕获近似为：

```text
单格毛收益率 ≈ 单格价差 / 基准价
单格净收益率 ≈ 单格毛收益率
              - 买卖双边佣金
              - 买卖双边滑点
              - 卖出税费
              - 未成交与追价的机会成本
```

在相邻网格成交后立即更新基准的模型里，一个完整往返通常赚的是“一格”，不是上下
两格相加。若价格约 1.40 元，0.001 元只有约 0.071%，很容易被现实摩擦吞掉。
因此脚本默认搜索 0.002～0.010 元，且强制固定差价必须是 0.001 元的整数倍。

费用必须换成你真实账户的 ETF 佣金和最低收费。默认 `1 bps`、最低佣金 0 只是研究
起点；若真实最低佣金为每笔 5 元，小额委托会完全改变最优手数和网格密度。

### 9.3 第三步：用波动确定候选间距

不要只挑历史收益最高的一个精确数字。先观察：

- 每日高低区间的中位数和 25%/75% 分位数；
- 1 分钟、5 分钟收益绝对值的分位数；
- 上午、下午及不同波动状态；
- 一格预计每天触发多少次。

一个实用起点是让单日中位区间大约容纳 4～12 个网格。如果典型日内区间为 2%，
可先搜索约 0.15%～0.50%，再以报价单位和交易摩擦设下限。太密会过度换手，太宽会
大部分时间不交易。

### 9.4 第四步：用资金容量反推每格数量

设预计最大向下层数为 `N_down`，每格买入 `Q` 份，粗略约束为：

```text
Q × N_down × 区间平均价格 + 费用缓冲 ≤ 可用于补仓的现金
初始持仓 + Q × N_down ≤ 最大持仓
初始持仓 - Q × N_up ≥ 保留底仓
```

对称网格通常从 40%～60% 初始仓位开始研究，让上下两侧都有操作空间。看多时可以
提高初始仓位或买入数量，看空时相反，但这已混入方向判断，不能再把所有收益归因于
网格本身。

### 9.5 第五步：设置价格区间和基准

- **基准价**决定第一组网格的位置。盘中启动可用创建时最新价；跨日策略可比较昨收、
  今开和上一成交基准。
- **有效区间**应和资金容量、历史波动区间及策略失效条件一起设计。跌破下限不应只是
  “停止买入”，还应有风险处置方案。
- **盘后更新**可以避免旧基准远离次日价格，但会改变策略连续性。回测时必须明确是否
  重置，不能在看到次日走势后再选择。

### 9.6 第六步：选择成交模式

- 关注成交确定性、资金允许双侧冻结：优先比较成交驱动型。
- 关注资券利用率、愿意承担触发后不成交：比较到价触发型。
- 希望过滤快速单边：到价型加入反弹/回落确认。
- 使用排队价：必须统计触发到成交耗时、未成交率和撤单率，不能把“触发次数”当
  “成交次数”。

### 9.7 第七步：控制过拟合

近 10 日只能用于检查流程和形成候选，不能证明参数长期有效。至少应继续做：

1. 按时间切分，验证段不参与参数选择；
2. 在训练和验证间按信号/持仓跨度留隔离期；
3. 滚动前推，例如每 20 日训练、隔离 1 日、随后 5 日验证；
4. 对佣金、滑点、漏单和成交延迟做压力测试；
5. 检查最优参数附近是否形成稳定平台，而不是只有一个尖峰；
6. 用更长历史覆盖单边上涨、下跌、低波动和高波动；
7. 用逐笔/盘口数据复核最终少量候选；
8. 模拟盘稳定后再考虑小资金实盘，保留硬性仓位和亏损上限。

### 10.3 排名口径

默认无隔离期时，脚本只用前 7 日训练数据计算排名分数：

```text
稳健分数 = 平均超越持有
         - 0.50 × 最差负超额
         - 0.15 × 超额收益标准差
         - 0.25 × 平均超额回撤绝对值
         - 0.002 × 日均成交笔数
         - 0.05 × 平均期末库存漂移
```

最后 3 日只展示验证结果，不参与排序；排名分数相同时，二级排序也不读取验证指标。这个
分数是为了在小样本下压制“高换手、尖峰
收益、尾部很差”的候选，不是通用金融指标；分数为负也不等于账户一定亏损，应同时
查看训练/验证超额收益、费用、成交数和逐日明细。

### 10.5 本次实际运行结果（截至 2026-08-28）

默认 234 组参数已全部跑完。当前稳健分数第一名是到价触发型：固定差价 0.010 元、

持有 0.0146%，验证段 0.0074%，验证段日均成交 3.33 笔。它在两个训练日收盘仍有
排队单，因此“排名第一”不能理解为没有执行风险。

成交驱动型第一名同样是 0.010 元、500 份：训练段平均超越持有 0.0151%，验证段
0.0131%，日均成交分别为 9.86 和 5.67 笔；它的原始超额不差，但换手和库存漂移
惩罚更高，在综合榜排第 20。这个例子说明参数选择不能只盯一个总分，也不能用验证
收益反过来挑参数。

把两种模式固定为相同的 0.005 元、1000 份，并关闭反弹/回落时，两边训练和验证的
日均成交数完全相同（34.43 / 18.00 笔）；成交驱动型训练/验证超额为
0.0448% / 0.0397%，到价型对手价口径为 0.0348% / 0.0343%。差异主要来自脚本给
到价型加入的 2 bps 滑点。这正是“两种流程看起来差不多”的可复现实证：当触发后
立即成交时，交易路径接近；加入排队、反转确认和滑点后才会明显分化。

在 2026-08-25 当天，上述到价型第一名成交 7 笔、收盘无待成交单、超越持有
0.0150%；成交驱动型第一名成交 8 笔、超越持有 0.0104%。这些数字只用于核查脚本
和理解状态机，不构成未来参数建议。

## 11. 当前回测必须牢记的边界

1. 分钟线只知道一分钟的开、高、低、收，不知道真实分笔顺序。项目用阳线
   `O→L→H→C`、阴线 `O→H→L→C` 的确定性路径，结果对同分钟先买还是先卖敏感。
2. 所有委托按整笔成交，未建模盘口深度、部分成交、成交量上限和队列位置。
3. 对手价和滑点是参数近似，无法替代实盘逐笔买一卖一。
4. 优化器每天独立恢复 10 万元和约 50% 仓位，用于公平比较；它故意不把隔夜跳空
   当成可成交路径，也不模拟多日账户连续复利。
5. 近 10 日只有 2400 根左右分钟线，足以验证程序，不足以估计长期收益分布。
6. 520500 是跨境/QDII ETF，还可能出现二级市场溢折价、境内外交易时段差异、停牌
   和流动性变化；价格震荡并不一定等于净值震荡。

因此，脚本输出应被理解为“哪一组参数值得进入下一轮检验”，而不是“已经找到可以买入
实盘的最优网格”。
